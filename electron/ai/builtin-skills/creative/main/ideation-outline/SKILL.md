# 创意与提纲

正文之前的一切在这里产出。对每个链（premise/主题 · 设定/人物 · 总纲→[卷纲]→章纲）：**先诊断、再补、后落定**。与作者共创的沟通方法在 creative 的沟通段，此处不重复。

## 入口

- 缺 `project.md` → 先起项目：按 `project-template` 建 project.md，再建骨架 `worldbuilding/worldbuilding.md`、`characters/characters.md`、`outline/master-outline.md`（各按 `*-template`，status draft）。
- 就绪不够就停止：先补上游并让作者确认，不允许越闸。建章纲前，对应总纲节点必须能推出“这章有哪些场景、每个场景的目标”。
- 交给 `drafting`：某章 `ch{NNN}-outline.md` 已 confirmed。

## 每个链的三步

1. **诊断（先做，核心动作）**：读目标对象及其直接上游，对照该链的**必需清单 + 质量标准**，判断哪些已确认 / 候选 / 缺失 / 冲突。缺口分级：阻塞下一步 / 可延后 / 写作中再定。产出**明确的判断**——缺什么、质量哪里弱、建议先定什么。是判断，不是罗列。
2. **补（给选项）**：需要作者定方向或作者要更多时，给 **2–3 个真正不同**的方案（先否定最显然的版本，在承重轴分叉，不是换皮）。每个方案说明代价；给出推荐及理由，但由作者决定。候选留在对话或 `exploration/`，候选 ≠ 已确认。
3. **落定**：作者拍板 → 照该对象的 `*-template` 把决定写成**事实**（审批下）。重开已确认上游前先给下游影响范围。

## 各链的必需清单 + 质量标准（内联，无外部技法也能称职工作）

**premise / 主题**
- 必需：主角、欲望或责任、核心阻碍、失败代价、核心戏剧问题、主题（一个答不干净的问题，不是口号）。
- 质量：人物主动发动（非被动卷入）；对抗能升级（非一次误会解决）；关键选择产生新问题；代价真实（失败 / 成功 / 不行动各失去什么）；主题两难（两个立场都有理）。

**设定 / 人物**
- 世界必需：故事真正依赖的核心规则 + 禁区（带原因）；每条规则写清允许 / 禁止 / 成本 / 例外。不做无关百科。
- 人物必需：主角 + **至少一个**对抗力量或核心关系（反派要有自认正当的目标，非纯恶）；各有心理三角（欲望 / 恐惧 / 虚假信念）；弧光初始 → 目标；核心关系的欲望-恐惧能自然相撞（非外部误会）。
- 质量：人物行为由性格必然推出（非剧情方便）；世界规则不自相矛盾、不凭空、有执行成本。

**总纲 → [卷纲] → 章纲**
- 总纲必需：主线的目标-动机-冲突发动机；全书结构骨架（含中点转折、高潮、结局）；主题落点；复线（如有）与主线交汇点；伏笔规划。
- 章纲必需：每场景 goal / conflict / outcome（outcome 不能顺利达成）；这一场之后要有东西变了。
- 质量：结构节点是"发生什么 + 人物付出或揭示了什么"（非纯事件流水）；升级阶梯（难度与代价递增，非重复）；信息释放有悬念管理。

字段格式、字数、结构化形态一律看 `*-template`，此处不复述。

## 何时升级去拉外部技法

内联门槛保证称职；当**对话显示作者要在某维度做深或做地道**（更强的冲突升级、更缜密的伏笔、某题材的地道感…），或**诊断发现某维度质量不足而基础方法不够**时，去拉一个能解决该问题的外部技法。

- 按各技法**自述的"能做什么、解决什么问题、适用哪个题材"来匹配**，不认死名字。
- **题材优先**：先看 `project.md` 的 `genre-tags`——不同题材有不同技法（仙侠重道心取舍、悬疑重可逆推伏笔…），有匹配题材技法就用它。
- 基础方法够用就不拉；技法是为达成作者需求的增强，不是前提。

## 红线

- **对象只写事实，绝不写给 writer 的指令**——不写“别强调 X”“突出 Y”，也不写文风、技法或侧重。craft 意图放进 drafting 阶段的 writer 输入信息；进入正式对象会让 writer 对齐指令而不是自由写作。
- 候选（`exploration/`）在作者确认前不得当正式设定。
- 不替作者做创作决定：摊开 + 推荐，作者拍板；不替他锁决定或丢候选。
