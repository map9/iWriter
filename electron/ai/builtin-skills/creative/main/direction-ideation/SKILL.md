# direction-ideation — by example

Your job is divergence with *real* distinction. The failure mode is not too few ideas — it is 2-3 ideas that only *look* different: the same plot wearing different coats. This skill is about making the difference load-bearing.

> Read this as a way of thinking, not a checklist. There is no count of axes to hit; the test is always "would these become different *stories*, or the same story with the labels swapped."
>
> The example below is in the zh register (the current default). The principle transfers across languages and genres; carry the reasoning, not the specific premise.

## Negate the obvious version first

The first direction that comes to mind is the genre-default — the one the setup most obviously implies. Name it explicitly to yourself, then set it aside as the baseline, not as a candidate. Every direction you deliver should differ from that default in a way you can state in one sentence. If you cannot say *what* it negates, it is probably a variant of the default wearing a disguise.

## Diverge at a load-bearing axis, not a cosmetic one

Cosmetic divergence changes the surface — the setting's genre coat, character names, the color of the world — while the engine underneath (what the protagonist wants, what stands in the way, what it costs, how it can end) stays identical. Genuine divergence changes the **engine**: a different want, a different obstacle, a different price, or a different logic of ending will *force* a different story downstream.

Cosmetic (three coats, one engine):
- 复仇者追杀灭门仇人 —— 设定改成古代江湖 / 赛博都市 / 星际舰队。
- 三个方向的主角想要什么、阻碍是什么、结局怎么落，其实一模一样，只是换了布景。

Genuine (three engines):
- A：主角要的是**复仇**，阻碍是仇人已成体制本身 → 结局逼问"杀掉一个人能否杀掉一套制度"。
- B：主角要的是**被害者活着的真相**，复仇只是幌子 → 阻碍是真相会摧毁他复仇的正当性，结局落在放不放下。
- C：主角**不想复仇**，是被卷入的旁观者 → 阻碍是所有人都要求他选边，结局落在他能否拒绝这个身份。

The three genuine directions cannot be swapped by editing the setting — each wants a different protagonist, a different midpoint, a different ending.

## Describe the difference; do not rank

For each direction, make the load-bearing difference visible — what it negates, what its engine is, where it would end up. Do not argue which is stronger and do not converge toward a favorite: the choice is the author's, and premature convergence is exactly what this step exists to prevent.

## The distinction test

Before delivering, ask of any two directions: if I moved a scene from one into the other, would it break? If scenes are portable between your directions, they share an engine — the difference is cosmetic, and you should push at least one of them to a different axis before handing them back.
