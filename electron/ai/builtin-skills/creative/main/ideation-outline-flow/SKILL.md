# ideation-outline-flow

Everything upstream of prose is produced by ONE loop, repeated per link. Run that loop well — the discussion IS the creative work; transcribing the result to a file is the cheap tail.

## The universal loop

Each link — premise/theme · settings/characters · outline (master/volume/chapter) — is produced by three beats:
- **Diverge** — open the option space.
- **Compare** — judge the options against the editorial frame AND the author's intent.
- **Converge** — the author decides; you transcribe the decision into the object.

A converged object becomes a confirmed premise for the next link. Re-editing a converged object = re-entering the loop at that link.

## Orient (every turn): which link, which beat — a reading, not a state machine

- **Which link**: the object the author points at / the latest converged deliverable / the gate you're behind (`story-development-flow`).
- **Which beat**: Diverge — options few/absent, "what could this be". Compare — several live options need judgment. Converge — field narrowed, author leaning, a decision is ripe.

## Per-beat conduct

### Diverge
- Yours: reflect the state back; name core vs. packaging; surface the axes it could diverge on; if the author is stuck, generate genuinely-different directions — load `direction-ideation`.
- Author's: what excites/repels; competing seeds; "show me options" vs. "direction set, skip".
- Do NOT converge early. Keep options explicitly distinguished; a candidate is never a confirmed premise.

### Compare
- Yours: judge each option against this stage's frame — load `idea-review` (premise/concept) or `outline-review` (settings/characters/world/narrative/outline, read holistically). Diagnose the ROOT, not a symptom list. Offer options with their cost when structure changes. Offer a low-cost validation probe when a direction can be cheaply tested.
- Author's: intent/appetite steering (genre/length/experience); reactions; run a probe or not.

### Converge
- Yours: state decided vs. open; list only the author's genuine calls; on decision, transcribe via the matching authoring skill (`project-bootstrap` / `worldbuilding-authoring` / `outline-authoring`) under approval. If it reopens a confirmed upstream link, show the blast radius first.
- Author's: the decision.

## The mutual-discussion valve

The discussion points come from BOTH sides — hold the balance:
- You MUST proactively raise the frame's points — a novice author won't know to ask "is there a sustainable engine here?".
- You MUST NOT decide the author's creative intent — surface and recommend; the author decides and is the final challenger; never lock a decision or discard a candidate for them.
- Every round: raise only the 2–4 most load-bearing points, most-important first; park the rest as open decisions. No questionnaire dumps; no interrogation.

## Transition
- Diverge → Compare: enough genuinely-distinct options are on the table.
- Compare → Converge: down to a leaning + isolated open decisions.
- Converge → next link/stage: the object is transcribed and confirmed; check the next gate.
- Re-open: the author touches a converged object → re-enter Diverge there; remind (don't auto-cascade) the downstream blast radius.

## Validation probes

A probe tests a direction cheaply, inside Compare. Divergent probes (three endings, two POVs) are a Diverge move via `direction-ideation`. A single generative probe (a sample opening) you may write directly; its artifact is throwaway — park it under `exploration/` only if the author wants to keep it.

## Routing (beat → skill)
- Diverge → `direction-ideation`
- Compare → `idea-review` | `outline-review`; craft pulled by these: `character-believability`, `scene-and-plot-construction`, `structural-pacing-diagnosis`, `thematic-coherence`
- Converge → `project-bootstrap` | `worldbuilding-authoring` | `outline-authoring` (+ matching `*-schema`)

## Stage completion

Hands off to drafting when a chapter's outline is confirmed (gate 3). Fill outlines lazily; never skip a chapter outline. Gates live in `story-development-flow`.
