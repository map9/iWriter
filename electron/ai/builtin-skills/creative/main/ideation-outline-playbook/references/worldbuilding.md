# 世界观任务模块

## 任务目标

建立故事真正依赖的规则、制度、空间与资源关系，让世界持续制造机会、限制和代价。世界观以“能改变人物选择和情节可行性”为边界，不追求百科全书式完备。

## 输入与入口

必读：

- `project.md`；
- 当前 `worldbuilding/` 目标文件；
- 直接受影响的主要人物事实；
- 作者本轮新增或修改的设定。

若 premise、reader-promise 或 narrative-engine 仍未成立，回立项任务；世界观不能替代故事核心。

## 工作流程

按作者要求执行理解、生成、评估、修复、比较或转录。生成与修复时：

1. 从故事核心冲突反推本作必须存在的规则、资源、组织和关键空间。
2. 对每个核心设定建立因果链：
   - 它是什么、允许什么、禁止什么；
   - 使用或违反它需要付什么成本；
   - 谁执行、维护或垄断它；
   - 谁获益、谁受损、谁会寻找漏洞；
   - 它怎样改变普通生活、权力关系或人物策略；
   - 它会在什么具体情境中被测试。
3. 地理重要时，再按环境 → 资源 → 生计 → 聚落/交通 → 权力关系推导；地理不承重时只建立故事需要的空间事实。
4. 检查不同规则的相互作用，找出至少一个会产生剧情的张力、漏洞或二阶影响。
5. 把未确认方向留为候选；作者明确要求落盘后，按 `worldbuilding-template` 写入正式对象。

## 最低语义验收

- **故事必要性**：删除某核心设定会改变冲突、人物策略或事件可行性；删掉毫无影响的只是装饰。
- **成本与边界**：核心规则有明确限制、成本或违反后果，不是随剧情方便开关的能力。
- **执行机制**：社会规则、禁令和资源分配能说明由谁执行、为什么仍有效；不能只写“所有人都遵守”。
- **二阶影响**：至少能推出一项非直接后果，例如职业、家庭结构、黑市、语言习惯、交通方式或权力分配的变化。
- **可利用性**：角色能够顺从、利用、绕开或反抗规则，规则因而进入选择和冲突。
- **具体测试**：每个承重规则至少能指出一个计划中的人物处境，说明它如何被测试以及代价落在谁身上。
- **内部一致**：规则之间无未解释的矛盾；存在例外时，例外有来源、代价和适用边界。
- **题材适配**：现实主义题材可以使用现实社会规则，不被迫制造宏大地理或超自然体系。

“宏大、丰富、生动、自洽”不算验收结论，必须指出上述哪条成立或失败。

## 交付形态

每项承重设定应让作者看清：

- 规则或现实条件本身；
- 运行机制、适用边界与成本；
- 执行、维护、垄断或挑战它的主体；
- 它改变人物日常生活、权力关系和行动策略的方式；
- 它与其他设定产生的张力或二阶后果；
- 它会在哪个计划中的人物处境里受到测试。

只交付与当前故事真正相关的设定。作者问具体可行性时，先给结论和依据，不扩写成世界百科。
