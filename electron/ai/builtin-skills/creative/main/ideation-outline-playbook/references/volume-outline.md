# 卷纲任务模块

## 目标

把总纲的一段全书变化组织成具有阶段性问题、升级过程和出口状态的一卷，不提前消费后续卷。

## 输入

仅在项目明确分卷时使用。读取 `project.md` 的相关制作信息、总纲目标范围、会推进的故事线阶段、主要人物的进入状态、相邻卷边界和当前卷纲目标块。

若总纲范围无法说明本卷要改变什么、推进哪些故事线，先回总纲。

## 工作方法

1. 用一至三句确定入口、持续施压的问题、关键变化和出口。
2. 设计必要阶段；每阶段一个因果句，说明人物办法、对抗回应和状态变化。
3. 后续阶段要改变策略、资源、认知、关系或代价，不按预计章节数平均切割。
4. 高潮使用本卷已经建立的人物、关系和规则，要求关键决定并产生兑现、新债务或下一压力。
5. 最后才根据戏剧负荷估算章节任务和顺序。

## 最低语义验收

- 结束点与总纲分配一致，没有提前消费后续核心转折。
- 本卷的阶段性问题在卷末得到回答。
- 入口和出口至少有一个承重状态发生具体变化。
- 各阶段由上一阶段的决定或后果触发。
- 压力在实际必要的多个维度升级，不把数值提升等同于人物成长。
- 卷末既兑现本卷承诺，也产生进入下一卷的具体条件。
- 章节数量来自戏剧动作，不来自固定配额。

## 交付与落盘

默认交付一个紧凑的本卷句、按因果排列的阶段和章节任务短表。关键语义可以合并表达，不拆成戏剧问题、入口状态、核心冲突、弧光阶段、高潮和出口状态六组字段。未获作者确认保持 `draft`。
