# 卷纲任务模块

## 任务目标

把总纲中的一段全书弧线变成具有独立戏剧问题、升级过程和阶段性结局的一卷，同时准确停在总纲分配给本卷的终点。

## 输入与入口

仅在 `project.md` 的 `scale-plan` 启用卷纲时使用。必读：

- `project.md`；
- 已确认或已稳定的总纲目标范围；
- 本卷承重人物及其进入本卷时的状态；
- 相邻卷已有的入口或出口状态；
- 当前目标卷纲。

若总纲范围无法说明本卷要改变什么、推进哪些人物与故事线，先回总纲任务。

## 工作流程

按作者要求执行理解、生成、评估、修复、比较或转录。生成与修复时：

1. 确定本卷进入状态、离开状态和贯穿本卷的戏剧问题。
2. 明确阶段性对抗：谁或什么持续阻止本卷目标，为什么这种阻力能够升级。
3. 设计若干因果阶段。每个阶段必须改变策略、资源、认知、关系或代价，不按章节数量平均切割总纲摘要。
4. 规划主要人物本卷弧光：从上卷末状态出发，经本卷测试推进到新的阶段，但不提前完成后续卷的变化。
5. 设计本卷高潮中的关键决定，以及决定造成的阶段性兑现、新债务或新压力。
6. 再根据戏剧负荷估算章节范围和章节列表；章节数来自内容，不来自固定配额。
7. 作者明确要求落盘后写入模板；未确认保持 `draft`。

## 最低语义验收

- **边界准确**：本卷没有提前消费后续卷的核心转折，结束点与总纲分配一致。
- **独立问题**：读者能说清本卷要解决什么，卷末对此有阶段性回答。
- **状态变化**：入口和出口在资源、关系、认知、处境或承诺上存在具体差异。
- **阶段因果**：各阶段由上一阶段的决定或后果触发，不是均匀分配事件。
- **升级多维**：本卷至少在两个维度增加压力；主角成长不要求匀速，也不把数值提升等同于人物成长。
- **高潮兑现**：高潮使用本卷已建立的人物策略、关系和规则，并迫使人物付出代价。
- **余波有效**：卷末既兑现本卷承诺，也产生进入下一卷的具体条件；不是只加一个无关悬念。
- **篇幅匹配**：章节数量与本卷的戏剧动作数量相称，不强制 15–25 章或固定爽点密度。

## 交付形态

卷纲应交付：

- 本卷进入状态、贯穿全卷的戏剧问题与目标离开状态；
- 持续施压的对抗机制；
- 按因果排列的阶段，每阶段说明策略、资源、认知、关系或代价怎样变化；
- 本卷内主要故事线和人物弧光的推进与交汇；
- 高潮中的关键决定、阶段性兑现及进入下一卷的具体条件；
- 由戏剧负荷推导的章节范围或章节任务。

卷纲不提前消费后续卷的核心转折，也不按固定章数均匀切割总纲。
