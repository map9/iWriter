# 人物任务模块

## 目标

建立能在具体处境中作出可辨认选择、影响他人并被后果改变的人物。人物记录必须支持章纲判断和正文表现。

## 输入

按任务读取 `project.md` 的相关故事约定、`characters/characters.md` 中的目标人物块、人物真正依赖的世界规则，以及直接相关的故事线、章纲或正文证据。先取目标 ID，不整读人物集合。

## 工作方法

生成、深化或修复人物时，在内部回答：

1. 此人在当前故事中想得到、守住或逃开什么，因此会主动做什么。
2. 面对压力时，他怎样理解局面，会使用什么具体办法；该办法为什么既有效又会制造代价。
3. 他具有什么能力、资源、知识和社会位置，哪些限制会排除看似直接的办法。
4. 他对重要他人的判断、索取、隐瞒和筹码是什么；面对不同对象时，语言和行动怎样变化。
5. 哪些经历能解释当前选择；正文可用什么措辞、身体动作、注意偏好或社交习惯让他可辨认。
6. 故事若要求人物变化，哪些递增处境会迫使他换办法、承担代价或跨过选择门槛。

用至少两个性质不同的处境测试重要判断；一次行为只算场景证据，不直接上升为稳定人格。
只保留能改变行动、关系、能力边界、声音或变化路径的结论。

## 最低语义验收

- **可辨认**：去掉姓名后，仍能从事实和处境推出此人区别于普通替代者的行动或说话方式。
- **能动**：主要人物会追求、隐瞒、交换、拒绝、控制或破坏，不只是承受剧情通知。
- **可解释**：重要选择与人物当时知道的事实、关系、资源和压力相容，不靠“剧情需要”。
- **关系双向**：核心关系双方各有所求和筹码，一次坦诚谈话不会无代价地抹平真实冲突。
- **变化有因果**：人物改变来自连续测试、选择和代价，不是遭遇事件后突然“成长”。
- **可写**：承重人物具有可重复但不机械的语言、动作或感知差异，能力、知识和限制足以约束场景选择。
- **证据适量**：记录只写能支持正文的稳定判断；不确定解释留在讨论或卡片中。

## 交付与落盘

按 `characters-template` 交付。配角使用核心句加零至两条补充；承重人物按需保留行动、关系、表现和条件，每条合并成直接事实句。人物变化过程写入独立故事线，人物卡只引用故事线 ID。

作者明确要求落盘时，把稳定事实压缩进 `characters/characters.md` 的目标人物卡。人物或关系如何跨事件变化属于故事线；已发生的即时状态属于章纲或正文。
