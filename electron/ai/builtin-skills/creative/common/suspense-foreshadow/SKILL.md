# 悬疑伏笔技法

## 解决什么

悬疑 / 推理里伏笔单薄的三种失败：真相揭晓后回看对不上（不可逆推）、没有误导（读者一眼看穿）、都是单线（无嵌套、无张力）。本技法把伏笔做到可逆推、有误导、成体系。

## 技法（设计或审查时逐条对照）

1. **可逆推**：真相揭晓后回看，每条埋设的细节都说得通、不矛盾——这是悬疑伏笔的底线。
2. **红鲱鱼配比**：误导线索与真线索约 1:1；红鲱鱼要有自洽的"看似成立"的假解释，不是硬凑一个错方向。
3. **看似无关的关键**：至少一条读者会觉得无关紧要、最终却是关键的细节。
4. **多层嵌套**：A 解开引出 B、B 解开引出 C，而非一次性揭底。
5. **无意泄露**：至少一处关键信息由角色无意间说漏，而非叙述者直给。
6. **专属类型**：给每根伏笔标一个悬疑常用类型，帮你想埋法——物证 / 不可靠叙述 / 误导证人 / 时间漏洞 / 沉默指控（该说而没说）/ 重复细节。

伏笔密度可比通用题材高。

## 落到哪

每根伏笔进对应埋设章的 `ch{NNN}-outline.md` 的 `foreshadow-ops`（埋 / 强化 / 收 + 内容 + 计划回收章）；把"真实指向"和"误导效果"写进埋设说明，供后续 consistency 核对可逆推性。伏笔格式看 `outline-template`，不做全书总表。

## 自检

- 每根伏笔真相揭晓后回看都对得上？
- 误导与真线索配比接近，红鲱鱼有自洽的假解释？
- 有没有那一条"看似无关"的关键？
- 是不是一次性揭底、缺嵌套？
- 关键信息是角色泄露的，还是叙述者直给的？
