# 发散方向技法

## 解决什么

发散的失败不是想法太少，而是 **2–3 个只是看着不同**：同一个故事换了外套。本技法让区别落在**承重处**——换了它，下游会长成不同的故事。

## 技法

**1. 先否定显然版**
最先想到的那个是题材默认版（setup 最明显推出的那个）。明确点出它，把它当**基线、不当候选**。你交付的每个方向都要能一句话说清它否定了默认版的什么；说不出否定了什么，多半是默认版换了层皮。

**2. 在承重轴分叉，不在装饰轴**
装饰性分叉改表面（题材外壳、人名、世界颜色），底下的引擎（主角想要什么、阻碍是什么、代价是什么、怎么收场）没变。真正分叉改**引擎**：不同的想要 / 不同的阻碍 / 不同的代价 / 不同的结局逻辑，会逼出不同的故事。

装饰（三层皮，一个引擎）：
- 复仇者追杀灭门仇人 —— 设定改成古代江湖 / 赛博都市 / 星际舰队。三个方向的主角想要什么、阻碍、结局其实一样，只换了布景。

真正（三个引擎）：
- A：要的是**复仇**，阻碍是仇人已成体制本身 → 结局逼问"杀一个人能否杀一套制度"。
- B：要的是**被害者还活着的真相**，复仇只是幌子 → 阻碍是真相会摧毁复仇的正当性，结局落在放不放下。
- C：**不想复仇**，是被卷入的旁观者 → 阻碍是所有人都逼他选边，结局落在他能否拒绝这个身份。

这三个换布景换不出来——各自要不同的主角、不同的中点、不同的结局。

**3. 可移植性测试（交付前验真）**
任取两个方向，把一个场景挪进另一个：会不会崩？场景能互相搬，就说明共用一个引擎＝换皮，把至少一个推到别的轴再交。

## 落到哪

产出的是**候选方向**，留在对话；作者想保留时再放入 `exploration/`，候选 ≠ 已确认。说明每个方向的区别与代价，并给出推荐及理由；推荐不是决定，最终由作者选择（决策与沟通方法见 creative 的沟通段）。

## 自检

- 每个方向能一句说清它否定了默认版的什么？
- 区别在引擎（想要 / 阻碍 / 代价 / 结局）还是在布景？
- 两个方向间挪一个场景会不会崩？崩才算真不同。
