# 人物可信度技法

## 解决什么

可信行为要能从人物当时掌握的信息、想守住或避免的东西、重要关系和可用办法推出。泛泛断言（“他内心矛盾”）推不出行为。

## 技法

1. **推一个行为**：此刻压力 → 人物怎样理解 → 想保住什么 → 选择哪种已有办法 → 谁会怎样回应。例：老周债已还清，被逼问线索；他只想彻底脱身，于是交代来源，却附加一个把阿坤拖得更深的条件。
2. 欲望、恐惧或错误认知只在能解释这条推导时使用，不为每个人强建完整心理模型。
3. 扁平通常不是缺背景，而是已有选择没有显出代价；先让现有办法在关系和行动中产生后果。

## 落到哪

稳定结论压缩进 `characters/characters.md` 的人物句或必要补充；本次行动写进对应故事线或章纲场景。写事实，不写分析标签；评审时作 finding。

## 自检

抹掉角色名与特征，换个普通人能否同样理由做同样事？能 → 是断言不是推导，重推。
