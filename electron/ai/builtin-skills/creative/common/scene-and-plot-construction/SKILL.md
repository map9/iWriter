# 场景与情节技法

## 解决什么

场景 = 目标 + 冲突 + 结果，**结果不能顺利达成**；节拍要**因果必要**（去掉触发还会发生吗？会 → 是装饰）。

## 技法

1. **场景形状**：POV + 具体短期目标 + 施压的对抗 + 转折（情势变 / 被迫选择 / 新信息落地）+ 留下不同状态的结果。写前填空"这场读者会发现〔角色〕的 ___"——必须关于他是谁，不是事件；填不出就没准备好。
2. **因果链**：先前状态 → 触发 → 角色解读 → 决定 → 行动 → 后果。查：无触发还发生吗 / 决定合他当前信息与压力吗 / 后果被下一拍记住吗 / 先前状态埋了所需资源吗。
3. **立得住的冲突**：换性格还在吗？在 → 是剧情驱动的误会（一次坦诚对话就化解）；重写成只有这两个人、这两个位置能生的冲突。

## 落到哪

进章纲 `scenes` 的 goal / conflict / outcome（**写事实**）；评审时作 finding。

## 自检

删掉这场，若只丢一个事件、读者对人物的理解不变 → 这场没干活。
