# 场景与情节技法

## 解决什么

场景必须让人物带着即时意图采取行动，引发具体回应，并留下不同于进入时的状态。去掉触发仍会原样发生的节拍只是装饰。

## 技法

1. **场景形状**：POV 人物为眼前想得到的东西采取办法；人物、制度或环境针对办法作出回应；新信息、选择或权力变化迫使他调整；结果改变下一场条件。
2. **因果链**：先前状态 → 触发 → 角色解读 → 决定 → 行动 → 后果。查：无触发还发生吗 / 决定合他当前信息与压力吗 / 后果被下一拍记住吗 / 先前状态埋了所需资源吗。
3. **立得住的冲突**：换性格还在吗？在 → 是剧情驱动的误会（一次坦诚对话就化解）；重写成只有这两个人、这两个位置能生的冲突。

## 落到哪

压缩成章纲中的一个场景因果句，必要时再补时空、POV 或信息差；不拆成方法字段。评审时作 finding。

## 自检

删掉这场，若只丢一个事件、读者对人物的理解不变 → 这场没干活。
