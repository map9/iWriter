# 项目模板

**前置 Skill：** `novel-workspace`

`project.md` 是作品级约定的唯一来源，不保存剧情进度、候选方向、人物档案或协作过程。

## 项目记录

```markdown
# 项目

## 作品（work）
暂名《二留一》，现实悬疑长篇，约二十万字，第三人称有限。

## 故事（story）
复制事件让两个拥有相同过去的陈默争夺唯一合法身份；当两人发现制度准备同时清除他们时，只能从互害转为联手，逼迫周围人重新决定“谁有资格成为一个人”。

## 创作边界（constraints）
- 主要体验：身份悬疑与亲密关系中的选择压力。
- 不写成纯粹善恶对决。
- 风格参照：styles/冷峻现实.md。
```

## 结构

- `work`：一句话合并书名、题材/形式、规模、读者、视角等已确认制作信息；只写当前真正需要的项目。
- `story`：一至三句保存作品核心约定，可以合并人物处境、行动压力、持续冲突、核心变化、主题问题和读者体验；具体是否成立由 `project-foundation.md` 检验。
- `constraints`：可选，最多三条作者明确要求保留或避免的边界，也可包含风格引用。

## 长度与变更

- `work` 默认一个句子。
- `story` 默认不超过三句或约 300 个中文字符。
- `constraints` 默认最多三条；只有作者明确给出更多硬边界时超过。
- 修改 `story` 中的核心行动压力、变化方向或读者体验时，提示人物、世界、故事线与提纲可能需要复核，但不自动改写。
- 修改规模、视角或风格引用时，只提示实际受影响的下游对象。
