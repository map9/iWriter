# Sensory Grounding — by example

Making an important scene physically present instead of abstractly emotional.

## The detail must do work

For an important scene, a grounded detail carries mood, pressure, danger, intimacy, status, or memory — it is not decoration. A useful move: one visual detail the viewpoint character would actually notice, plus one non-visual sense (sound, touch, smell, temperature, texture, bodily sensation), each earning its place by revealing something.

反例（emotion label + abstract atmosphere）："仓库里气氛很紧张，他感到害怕。"
正例（grounded, load-bearing）："仓库里只有头顶一盏灯，冷得能听见自己咽口水的声音。老周的皮鞋在水泥地上蹭了一下，阿坤的后颈立刻绷紧了。"

The cold, the swallow, the shoe scraping — each carries the tension the label only names.

## Character filter

The same room feels different through different people. Before drafting, ask:
- What is the character trying *not* to notice?
- What detail does their current emotion make louder?
- What would a calmer person ignore that this character can't?

## When not to use

Skip for fast transitions, multi-day summaries, direct exposition, or scenes where speed matters more than embodiment. Do not run a sensory checklist over every paragraph.
