# 世界观设定模板

**前置 Skill：** `novel-workspace`

## 管理对象

```text
{workspace}/worldbuilding/worldbuilding.md
```

全部世界观设定保存在一个文件中。每项按作品里的名称建立 H2 条目和稳定 ID，不预设分类栏目。

## 设定条目

```markdown
## 复制事件（world-duplication）

事件会产生两个拥有事前同一记忆、此后各自独立的人；社会只承认一个合法身份，因此裁决所必须在期限内完成“二留一”。

- 事件后新增记忆不会同步，任何一方受伤或死亡也不会影响另一方。
- 登记系统冻结原身份，由裁决所通知亲属投票，并在七日内注销落选者。
- 两人共用旧证件却各持一张临时灰卡；公共终端把两人的姓名标成同一个红色编号。

## 第三裁决所（world-third-tribunal）

裁决所设在废弃婚姻登记中心，负责复制身份争议；它靠冻结账户和亲属投票迫使当事人到场，公开程序强调家庭选择，内部执行组则准备处理无人服从的结果。

- 等候区、投票室和地下执行通道彼此隔离，家属看不到当事人被带往哪里。
- 窗口员只解释票面规则，执行组掌握冻结与押送权，主任可以延迟但不能取消裁决。
- 广播沿用婚姻登记的温和女声，灰墙上还留着撕掉的双喜字胶痕。
```

## 记录要求

- 每个条目先用一至三句说明它是什么、怎样影响故事中的生活或人物选择。
- 简单设定不加补充；重要设定默认增加一至六条正文会使用的事实。超过时只保留无法合并、且会独立改变规则边界、行动条件或正文表现的已确认事实，不为满足条数截断。
- 补充事实按作品中的人、规则、程序、地点、物件、称呼或现象直接起句，不写类别名或固定字段。
- Agent 按当前设定实际承担的作用检查运行方式、边界、代价、执行者、空间与资源、历史后果、使用方式和准确称呼；只记录会改变故事的部分。
- 至少保留一种能进入正文的具体事实：人物要执行的程序、可采取的动作、会遇到的物件或语言、空间限制或感官特征。
- 可独立引用的设定使用独立 ID；其他对象只引用 ID。

## 写作可用性

重要设定进入章纲或正文前，Agent 必须能从条目和直接引用判断：

- 什么能发生、不能发生，违反或绕开会付出什么；
- 谁执行、使用、垄断或反抗，人物会遇到什么程序；
- 空间、资源或物品怎样限制和提供行动；
- 读者能从什么具体动作、语言、物件或感官细节看见该设定。

## 归属

- 只保存会改变人物选择、行动可行性、资源分配、社会行为或正文表现的稳定事实。
- 人物当前位置、物品当前持有人、阵营当前胜负等动态状态写入章纲或正文。
- 未确认设想留在卡片；同一事实只保留一个条目。
