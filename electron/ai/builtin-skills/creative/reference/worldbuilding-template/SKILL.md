# 世界设定模板

**前置 Skill：** `novel-workspace`

## 管理对象

```text
{workspace}/worldbuilding/worldbuilding.md
```

规则、地点、组织、历史、物品和术语保存在一个文件中，以稳定 ID 的 H2 条目区分。

## 设定卡

```markdown
## 复制事件（world-duplication）

事件会产生两个拥有事前同一记忆、此后各自独立的人；社会只承认一个合法身份，因此裁决所必须在期限内完成“二留一”。

- 边界：事件后新增记忆不会同步，任何一方受伤或死亡也不会影响另一方。
- 运作：登记系统冻结原身份，由裁决所通知亲属投票并在七日内注销落选者。
- 可写表现：两人共用旧证件却各持一张临时灰卡，公共终端会把两人的姓名标成同一个红色编号。

## 第三裁决所（world-third-tribunal）

裁决所设在废弃婚姻登记中心，负责复制身份争议；它靠冻结账户和亲属投票迫使当事人到场，公开程序强调家庭选择，内部执行组则准备处理无人服从的结果。

- 空间：等候区、投票室和地下执行通道彼此隔离，家属看不到当事人被带往哪里。
- 人与程序：窗口员只解释票面规则，执行组掌握冻结与押送权，主任可以延迟但不能取消裁决。
- 可写表现：广播沿用婚姻登记的温和女声，灰墙上还留着撕掉的双喜字胶痕。
```

## 类型要求

- 规则或系统：运行条件、硬边界、成本或例外、执行者、可利用后果。
- 组织或制度：目标与权力来源、资源、程序、内部限制、公众接触方式。
- 地点：空间关系、出入与交通、资源和控制者、行动限制、感官标记。
- 历史事件：起因、仍在生效的结果、不同群体如何记忆或利用。
- 物品或技术：能力、使用条件、限制、代价、痕迹和保管方式。
- 术语或习俗：准确含义、使用者、适用场合及会导致错误行动的边界。

## 记录要求

- 每个条目用核心句说明它是什么、怎样运行及怎样影响人物选择。
- 简单条目最多三条补充；承重条目选用必要功能行，默认不超过六条。
- 每条功能行合并一个相互依赖的事实组；没有故事作用的类别省略。
- 至少保留一种正文可见的表现：程序、动作、物件、语言、空间限制或感官标记。
- 独立规则、地点、组织、物品或术语使用独立 ID；其他对象只引用 ID。

## 写作可用性

承重设定进入章纲或正文前，记录必须足以判断：

- 什么能发生、不能发生，违反或绕开会付出什么；
- 谁执行、使用、垄断或反抗，人物会遇到什么程序；
- 空间、资源或物品怎样限制和提供行动；
- 读者能从什么具体动作、语言、物件或感官细节看见该设定。

## 归属

- 只保存会改变人物选择、行动可行性、资源分配、社会行为或正文表现的稳定事实。
- 人物当前位置、物品当前持有人、阵营当前胜负等动态状态写入章纲或正文。
- 未确认设想留在卡片；同一事实只保留一个条目。
