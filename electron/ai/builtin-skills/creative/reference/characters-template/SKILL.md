# 人物小传模板

**前置 Skill：** `novel-workspace`

## 管理对象

```text
{workspace}/characters/characters.md
```

全部人物保存在一个文件中。每个人物使用稳定 ID；块级工具按 ID 定位。

## 人物小传

每个人物使用一个 H2：

```markdown
## 陈默（char-chenmo）

32岁设计院副院长，复制后必须与另一个自己争夺唯一身份和家庭位置，最怕亲近的人认定他是“多出来的那一个”。

- 面对压力，他先试探对方底线，再以人情或信息换取退让；这能暂时保住体面，也常把冲突拖成背叛。
- 与苏晚（char-suwan）：他把她视为唯一不会抛下自己的人，越怕她作出选择，越会隐瞒和控制。
- 左肋旧伤：曾替魏志红打架受伤并住院两个月，旧伤限制持续对抗。
- 说话时先铺垫、很少直接拒绝；紧张时反复摩挲左肋。
- → line-chenmo-identity
```

## 记录要求

- 用一段小传合并人物身份、故事处境、目标或动机，以及足以区分他的性格和行为。
- 配角默认只写小传；主要人物可增加一至六条正文会使用的事实。
- 补充事实按内容直接起句，可用人物、经历、习惯、物件或地点作提示词；不设固定字段。
- 人物关系写清他怎样看待对方、想从对方那里得到或隐瞒什么，以及惯常怎样相处；引用对方 ID。
- 经历、能力、资源、局限、知识范围、说话方式、身体习惯和有叙事作用的外貌只在影响故事时记录。
- 人物变化过程保存在 `storylines.md`；人物小传只写 `→ 故事线 ID`。
- 同一事实已经进入小传时不再写成补充；每条补充只保留一个相互依赖的事实组。

## 写作可用性

主要人物进入章纲或正文前，Agent 必须能从小传和直接引用判断：

- 他在压力下会采取什么办法，以及为什么；
- 他面对当前关系对象时怎样说、怎样做、想取得或隐瞒什么；
- 他能做什么、知道什么、受什么限制；
- 正文可反复使用的声音、动作或感知差异。

## 归属

- 稳定身份、性格与行为、经历、能力、局限、知识范围、人物关系和可观察特征写在人物小传。
- 人物变化和关系变化写入故事线；人物小传只保留稳定起点和故事线引用。场景中的即时关系状态写入章纲或正文。
- 当前位置、当前伤势、持有物和已发生行动以章纲和正文为准。
- 未确认判断和孤立场景想法留在卡片；一次行为不写成稳定人格。
- 同一关系事实只在最适合维护的一方写完整内容，另一方只引用。
