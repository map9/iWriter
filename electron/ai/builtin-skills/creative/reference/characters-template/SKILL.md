# 人物模板

**前置 Skill：** `novel-workspace`

## 管理对象

```text
{workspace}/characters/characters.md
```

新项目把全部人物放在一个文件中，不为主角或重要配角另建个人档案。块级工具按人物 ID 定位。

## 人物卡

每个人物使用一个 H2：

```markdown
## 陈默（char-chenmo）

32岁设计院副院长，习惯用顺从和回避保住体面；归属或生存受到威胁时，他会先讨好、再暗中算计，最怕别人认定他是“多出来的那一个”。

- 已确定经历：曾替魏志红打架受刀伤，住院两个月。
- 重要关系：把苏晚视为唯一不会抛下自己的人，因此最怕她作出选择。
- 正文抓手：说话先试探，很少直接拒绝。
```

核心句保存足以区分人物并预测其故事行动的事实。补充项只在已确认且正文会用到时增加，通常不超过三条。

## 内容边界

- 保存相对稳定的身份、经历、资源、限制、关系事实和可观察表现。
- 欲望、恐惧、错误认知、惯用策略、矛盾与弧光是人物任务可使用的分析视角，不是必填字段。
- 只有某项判断能解释或预测具体行动时才写入，并用自然的故事语言合并表达。
- 关系可以写在最适合维护的一方卡片中；另一方只引用，不保存同一事实的反向改写副本。
- 即时位置、伤势变化、持有物、关系输赢和当前弧光进度以章纲和正文为准。

## 长度与升格

- 一般人物：一个核心句，必要时一至三条补充。
- 重要人物可以增加带稳定 ID 的 H3 子条目，但仍留在本文件。
- 一次行为不能自动上升为稳定人格；没有足够证据时保留为卡片或具体场景事实。
- 旧项目的独立人物档案继续原位维护，未经作者批准不迁移或复制到本文件。
