# 人物模板

**前置 Skill：** `novel-workspace`

## 管理对象

```text
{workspace}/characters/characters.md
```

全部人物保存在一个文件中。每个人物使用稳定 ID；块级工具按 ID 定位。

## 人物卡

每个人物使用一个 H2：

```markdown
## 陈默（char-chenmo）

32岁设计院副院长，复制后必须与另一个自己争夺唯一身份和家庭位置，最怕亲近的人认定他是“多出来的那一个”。

- 行动：受压时先试探对方底线，再以人情或信息换取退让；这能暂时保住体面，也常把冲突拖成背叛。
- 关系：把苏晚（char-suwan）视为唯一不会抛下自己的人，越怕她作出选择，越会隐瞒和控制。
- 表现：说话先铺垫、很少直接拒绝；紧张时反复摩挲左肋旧伤。
- 条件：熟悉设计院的人事关系，曾替魏志红打架受刀伤并住院两个月；左肋旧伤限制持续对抗，手中没有裁决所的正式资源。
- 变化线：line-chenmo-identity。
```

## 记录要求

- 核心句：合并稳定身份、故事处境和主要驱动力；简单人物可把行动倾向并入核心句并省略 `行动` 行。
- `行动`：合并所求或所护、局面判断、惯用办法及其代价。
- `关系`：每条只写一段承重关系，包含对对方的判断、索取或回避、可用筹码及相处方式；引用对方 ID。
- `表现`：合并声音、措辞、身体习惯、社交动作和有叙事作用的外貌标记。
- `条件`：合并能解释行动的经历、能力、资源、限制和知识边界。
- `变化线`：只引用人物变化线 ID；变化过程和阶段保存在 `storylines.md`。
- 配角默认核心句加零至两条补充；承重人物选用必要功能行，默认不超过六条。
- 每条功能行只写一个相互依赖的事实组，不设空标题，不逐项展开分析词。

## 写作可用性

承重人物进入章纲或正文前，记录必须足以判断：

- 他在压力下会采取什么办法，以及为什么；
- 他面对当前关系对象时怎样说、怎样做、想取得或隐瞒什么；
- 他能做什么、知道什么、受什么限制；
- 正文可反复使用的声音、动作或感知差异。

## 归属

- 稳定身份、行动倾向、经历、能力、限制、知识边界、关系判断和可观察表现写在人物卡。
- 人物变化和关系变化写入故事线；人物卡只保留稳定起点和故事线引用。场景中的即时关系状态写入章纲或正文。
- 当前位置、当前伤势、持有物和已发生行动以章纲和正文为准。
- 未确认判断和孤立场景想法留在卡片；一次行为不写成稳定人格。
- 同一关系事实只在最适合维护的一方写完整内容，另一方只引用。
