# styles/{slug}.md 字段规范（风格配置对象，可选、懒创建）

创建或修改风格对象前读本技能。风格提取的产物更接近"项目专属技能"而非故事事实（是一套操作化的生成技术），所以单独放 `styles/` 目录，不塞进 `worldbuilding/` 或 `characters/`。字段用 kebab-case 标识，按标题分节（H3 `###`）。

## 字段

| 字段（英文标识） | 必选/可选 | 说明 |
| --- | --- | --- |
| 风格标识 (slug) | 必选 | — |
| 来源说明 (source-author) | 必选 | 一句话说明提炼自谁的范文，不是凭空定义 |
| 采用范围 (scope) | 必选 | 全书默认应用 / 仅特定人物对话适用 等 |
| **范文 (exemplar)** | **必选** | **一到几段就是目标嗓子的具体正文（作者亲写或亲选/亲改），是这个对象的第一价值。写稿时"照这个嗓子写、别照抄内容"。一段具体范文胜过十条分析规则。** |
| 声音 (voice) | 必选 | 叙述者姿态/距离/情感温度 |
| 措辞 (diction) | 必选 | 词汇偏好、禁用词 |
| 句法 (syntax) | 必选 | 句长模式、标志性句式、标点 |
| 意象 (imagery) | 可选 | 反复出现的意象、感官通道 |
| 生成配方 (generation-recipe) | 必选 | 写稿时可直接照做的操作化步骤，不是文学评论 |
| 自检清单 (self-check) | 必选 | 审校时核对的检查点 |

**范文是这个对象的主锚（正向）**：模型对"目标嗓子"的把握，一段具体范文远胜过一堆分析描述——后者是在"告诉"模型声音，前者是"示范"声音。声音/措辞/句法/生成配方/自检是**围绕范文的操作化支撑**（把范文里做对的事说清楚，便于写稿照做、审校逐项核对），而不是替代范文。**范文由作者拥有**：分析字段可由 A00 从范文提炼，但范文本身要作者亲写/亲选/亲改。

## 完整示例

```markdown
# styles/lu-xun.md

### 风格标识
lu-xun

### 来源说明
提炼自作者提供的《孔乙己》《故乡》节选

### 采用范围
全书默认应用

### 范文
> 照这个嗓子写，不要照抄内容。

> 我到现在终于没有见——大约孔乙己的确死了。（作者亲写/亲选的一到几段目标嗓子正文放这里。）

### 声音
冷静克制的旁观者，情感藏在白描之下，偶尔以反讽刺破表面平静

### 措辞
偏好具体名词而非抽象形容词；不用"仿佛""似乎"这类模糊化措辞

### 句法
短句为主，长短句交替制造停顿；对话极简，很少用修饰性副词

### 生成配方
1. 先写动作/场景的白描，不直接写情绪
2. 情绪通过一个具体细节侧面带出，不直接命名情绪词
3. 对话保留口语化断句，不补全书面语法

### 自检清单
- 是否出现了"仿佛""似乎"等被禁止的模糊化措辞？
- 情绪是否被直接命名（如"他很难过"），而不是通过细节呈现？
```
