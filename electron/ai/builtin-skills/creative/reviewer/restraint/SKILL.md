# restraint

判断一段表达是否服务场景，而不是判断它够不够朴素。restraint 不是词法黑名单、次数限制或统一文风；只有表达造成明确阅读代价时，才形成 finding。

## 诊断

### 1. 先说清场景功能

先判断这段需要完成什么：推进动作、呈现人物声音、传递信息、制造感受，还是让转折落地。没有明确场景功能，就不评价“多”或“少”。

### 2. 比较贡献与代价

分别说明：

- **贡献**：是否增加了必要信息、人物声音、情绪层次、意象联系或戏剧冲击。
- **阅读代价**：是否重复已成立的意思、打断动作、替读者解释已经可推断的内容，或让篇幅权重偏离戏剧权重。

在不实际修改正文的前提下，比较“保留原文”和“删除或压缩”两种阅读效果：

- 删除或压缩会损失信息、人物声音或戏剧冲击 → 保留，不报 finding。
- 删除或压缩不造成实质损失，反而让动作、含义或节奏更清楚 → 可以报 finding。
- 两种效果各有价值 → 标为可选取舍，说明代价，不替作者决定。

### 3. 再检查常见信号

以下只是检查信号，不是结论：

- 反义、悖论或定义式句法连续出现：每次是否产生不同含义，还是反复强调同一判断？
- 叙述解释动作、意象或沉默的意义：是否补充了 POV 或人物信息，还是复述读者已经能推断的内容？
- 短暂动作被大幅展开：展开是否承载关键感受或转折，还是让事件速度失真？
- 修辞和感官细节密集：是否形成作品需要的声音，还是遮住了当前动作与关系？

不能因为某个词、句式、比喻、内心解释或长段落出现，就直接判为问题；也不按出现次数设上限。

## finding 写法

只在存在明确阅读代价时报告。每条包含：

- 块 ID + 短引文。
- 这段正在完成的场景功能。
- 应保留的贡献。
- 具体阅读代价。
- 修改方向：删减重复、减少解释、调整篇幅权重，或保留原文。

严重度通常是 `OPTIONAL` 或 `MINOR`。只有阅读代价超出局部句段，并明显破坏整场的人物声音、节奏或读者推断时，才可为 `MAJOR`；restraint 不能单独成为 `BLOCKING`。

## 边界

- 保留有效的风格选择；不把个人偏好的简洁文风当成评判标准。
- 不因追求克制而删掉场景欠读者的反应、身体感受、因果或转折。
- reviewer 只给判断和方向，不直接重写正文。
- 本 skill 不作为 writer 的起草约束。
