# 安全说明

> 适用版本：iWriter `0.1.21`
>
> 最后更新：2026-06-22

## 安全边界

- iWriter 以本地文件优先，不会默认把文档上传到 iWriter 官方服务。
- AI 请求仅在你主动使用 AI 功能时发送到你配置的第三方 Provider。

## AI 安全实践

1. 不在提示中发送敏感个人信息或密钥。
2. 为不同环境使用独立 API Key。
3. 定期轮换密钥并最小化权限。

## 编辑安全

- Edit 模式采用 proposal/HITL 审批机制。
- 未经审批的提案不会直接写入文件。

## 漏洞反馈

如发现安全问题，请通过仓库 Issue 或维护者公开渠道联系。

- 仓库地址：<https://github.com/map9/iWriter>
