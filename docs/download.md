## 安装步骤

1. 根据你的操作系统下载对应安装包。
2. 双击安装包并按向导完成安装。
3. 首次启动后，使用“打开文件夹”选择一个本地工作区。

## 升级方式

### 自动更新

- 生产环境下会检查并提示可用更新。
- 支持跳过版本和手动检查更新。

### 手动更新

1. 前往 Releases 下载新版本安装包。
2. 关闭 iWriter 后执行安装覆盖。
3. 启动并确认版本号。

## 常见安装问题

### macOS 提示来源不明

- 在系统设置中允许该应用后重试。
- 企业设备可能受安全策略限制，请联系管理员。

### Windows 被安全软件拦截

- 先校验下载来源是否为官方仓库。
- 将安装目录加入信任白名单后重试。

### 无法自动更新

- 检查网络是否可访问 GitHub Releases。
- 确认当前不是开发环境。
