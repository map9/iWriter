# 路线图

> 适用版本：iWriter `0.1.24`
>
> 最后更新：2026-07-27

## 已落地

- 本地文件优先的 Markdown / 富文本编辑与工作区管理
- AI Edit 对话、研究、块级编辑与提案审批流
- AI Creative 纯 Markdown 小说项目、三层提纲、正文写作会话、评审、重构与导入
- 标准 Git 源代码管理、Diff、冲突合并、Graph、Timeline、分支、远程、Stash 与 Tags

## 后续方向

- 强化个人知识库的结构化发现、引用与整理
- 持续改进 Creative 的长篇上下文、项目诊断和专业编辑能力
- 改进大仓库 Git 性能、历史导航与更细粒度 Diff 操作
- 完善跨平台体验、导入导出格式和无障碍支持

## 说明

路线图用于表达方向，不等于发布时间承诺。具体优先级以实际版本发布说明为准。
