# 文档中心

> 适用版本：iWriter `0.1.24`
>
> 最后更新：2026-07-27

欢迎来到 iWriter 使用文档。

## 当前能力

- 本地文件优先的 Markdown / 富文本写作与工作区管理
- 内置 Git 源代码管理、Diff、冲突合并、Graph 与 Timeline
- AI Edit 模式的文档研究、块级编辑和提案审批
- AI Creative 模式的纯 Markdown 小说项目、三层提纲、正文写作、评审、重构与导入
