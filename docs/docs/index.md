# 文档中心

> 适用版本：iWriter `0.2.0`
>
> 最后更新：2026-07-28

欢迎来到 iWriter 使用文档。

## 当前能力

- 本地文件优先的 Markdown / 富文本写作与工作区管理
- 内置 Git 文档版本管理、Diff、冲突合并、Graph 与 Timeline
- 日常写作搭子（AI Doc Buddy）的文档研究、知识整理、内容创作、块级编辑和提案审批
- 小说创作搭子（AI Story Buddy）的纯 Markdown 小说项目、三层提纲、正文写作、评审、重构与导入
