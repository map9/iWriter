# 工作区与文件管理

> 适用版本：iWriter `0.1.6`
>
> 最后更新：2026-04-29

## 工作区基础

- 通过“打开文件夹”将本地目录载入为工作区。
- 左侧 `Explorer` 展示树形结构。

## 文件树操作

支持以下常见操作：

- 新建文件
- 新建文件夹
- 重命名
- 移动
- 删除

## 外部变更同步

iWriter 会监听工作区文件变化，并同步刷新文件树。

适用场景：

- 你在外部编辑器改动了文件
- 你通过命令行新增/删除了文件

## 多标签与恢复

- 支持同时打开多个文件标签页。
- 关闭应用后会恢复工作区与已打开文件状态。

## 只读与保存

- 支持只读模式。
- 支持自动保存、另存为、全部保存。
