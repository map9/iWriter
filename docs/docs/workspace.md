# 工作区与文件管理

> 适用版本：iWriter `0.1.10`
>
> 最后更新：2026-05-08

## 工作区基础

- 通过“打开文件夹”将本地目录载入为工作区。
- 左侧 `Explorer` 展示树形结构。
- 工作区基于操作系统真实目录，不额外引入私有数据库或远程文件服务。
- 顶部搜索框可用于快速过滤当前资源树中的文件与文件夹。

## 文件树操作

支持以下常见操作：

- 新建文件
- 新建文件夹
- 重命名
- 移动
- 删除
- 拖拽调整目录结构
- 在资源管理器 / Finder 中定位文件（通过系统壳层能力）
- 只读文件与隐藏文件会以更弱的视觉样式显示，便于快速识别

## 外部变更同步

iWriter 会监听工作区文件变化，并同步刷新文件树。

适用场景：

- 你在外部编辑器改动了文件
- 你通过命令行新增/删除了文件

## 工作区忽略规则

iWriter 支持在工作区根目录放置 `.iwtignore` 文件，用来隐藏暂时不希望出现在资源树或跨文件搜索结果中的内容。

适用场景：

- 忽略构建产物、缓存目录或同步生成文件
- 临时排除不参与写作的素材目录
- 减少跨文件搜索时的噪声结果

规则说明：

- 一行一条规则，语法接近 `.gitignore`
- 支持 `*`、`**`、`?`
- 支持以 `!` 开头写反向包含规则
- 支持目录规则，例如 `temp/`

## 多标签与恢复

- 支持同时打开多个文件标签页。
- 关闭应用后会恢复工作区与已打开文件状态。
- 适合在长文写作、查资料、跨文件比对时保持上下文连续。

## 只读与保存

- 支持只读模式。
- 支持自动保存、另存为、全部保存。

## 适合的工作方式

- 用一个文件夹管理整本书、整套笔记或整批草稿
- 配合 `Search` 面板执行跨文件检索与替换
- 让 AI 在目录、文档、图片、PDF 之间协同取材
