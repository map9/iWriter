# 工作区与文件管理

> 适用版本：iWriter `0.1.24`
>
> 最后更新：2026-07-27

## 工作区基础

- 通过“打开文件夹”将本地目录载入为工作区。
- 左侧 `Explorer` 展示树形结构。
- 工作区基于操作系统真实目录，不额外引入私有数据库或远程文件服务。
- 顶部搜索框可用于快速过滤当前资源树中的文件与文件夹。

## 文件树操作

支持以下常见操作：

- 新建文件
- 新建文件夹
- 重命名
- 移动
- 删除
- 拖拽调整目录结构
- 在资源管理器 / Finder 中定位文件（通过系统壳层能力）
- 复制绝对路径或相对于当前工作区的路径
- 只读文件与隐藏文件会以更弱的视觉样式显示，便于快速识别
- Git 仓库中的文件会显示新增、修改、删除、重命名或冲突状态；目录显示子树聚合状态

## 外部变更同步

iWriter 使用操作系统原生文件监听能力同步刷新文件树、搜索与 Git 状态。

适用场景：

- 你在外部编辑器改动了文件
- 你通过命令行新增/删除了文件
- 你在命令行或其他 Git 客户端切换分支、提交或还原文件

在 Windows 上，如果工作区里包含 NTFS 联接点、重解析点等系统对象，iWriter 会跳过无法读取的对象并继续同步其他文件，通常不需要手动处理。

当外部修改与 iWriter 内部保存同时发生时，保存流程会校验并合并最新状态，避免用旧缓冲区覆盖新文件或生成 0 字节文件。Diff 编辑页同样会检查打开后的外部修改；磁盘内容已变化时会要求重新载入。

## 工作区忽略规则

iWriter 支持在工作区根目录放置 `.iwtignore` 文件，用来隐藏暂时不希望出现在资源树、跨文件搜索或文件监听中的内容。`.gitignore` 默认只表达 Git 版本管理边界；如果你希望复用它，可以在偏好设置中分别开启资源管理器、跨文件搜索或文件监听的 Git 忽略规则联动。

适用场景：

- 忽略构建产物、缓存目录或同步生成文件
- 临时排除不参与写作的素材目录
- 减少跨文件搜索时的噪声结果

规则说明：

- 一行一条规则，语法接近 `.gitignore`
- 支持 `*`、`**`、`?`
- 支持以 `!` 开头写反向包含规则
- 支持目录规则，例如 `temp/`
- 默认会跳过 `.git/`、`.iwriter/`、`.DS_Store`、`._*`、`__MACOSX` 等版本控制、iWriter 工程态与系统元数据；依赖目录、构建产物、缓存目录或大型素材目录需要时可写入 `.iwtignore`，或按功能开启 `.gitignore` 规则复用

## 多标签与恢复

- 支持同时打开多个文件标签页。
- 关闭应用后会恢复工作区与已打开文件状态。
- 适合在长文写作、查资料、跨文件比对时保持上下文连续。
- 标签页右键菜单支持关闭当前、关闭其他、关闭已保存、关闭全部、定位文件、复制路径，以及对可导入 Office 文件执行导入。
- Git Diff 和冲突合并也会作为标签页打开，但不会加入下次启动的文档恢复列表。

## Git 版本控制

左侧 Source Control 面板可以直接管理工作区根目录的标准 Git 仓库，包括：

- 初始化或克隆仓库
- 查看、暂存、放弃和提交变更
- 编辑 Diff 与解决冲突
- 管理分支、远程、Stash 和 Tags
- 查看仓库 Graph 与单个文件的 Timeline

完整操作见 [Git 源代码管理](/docs/source-control)。

## Windows / Linux 标题栏与窗口控制

在 Windows 和 Linux 上，iWriter 使用无系统边框的自定义标题栏，右侧提供最小化、最大化 / 还原和关闭按钮。窗口最大化或退出全屏后，标题栏会同步切换最大化 / 还原状态。

侧边栏显示时，应用菜单入口位于左侧侧边栏顶部；隐藏侧边栏后，应用菜单入口会移到标题栏左侧。该菜单可打开主菜单、偏好设置、关于窗口和退出操作，并会根据当前是否有活动文档和文档类型过滤可用项。macOS 仍使用系统菜单栏与交通灯窗口按钮。

## 只读与保存

- 支持只读模式。
- 支持自动保存、另存为、全部保存。

## 适合的工作方式

- 用一个文件夹管理整本书、整套笔记或整批草稿
- 配合 `Search` 面板执行跨文件检索与替换
- 让 AI 在目录、文档、图片、PDF 之间协同取材
