# 搜索与替换

> 适用版本：iWriter `0.1.17`
>
> 最后更新：2026-06-07

## 文内搜索与替换

用于当前打开文档，适合快速定位并批量修订。

适合场景：

- 修改当前章节中的高频术语
- 检查某个片段是否重复出现
- 在落稿前统一格式或标点

## 跨文件搜索与替换

`Search` 面板支持在工作区内执行全文搜索与替换。

支持能力：

- 正则表达式
- 区分大小写
- 全词匹配
- 搜索历史记录
- `Files to include` 过滤范围
- `Files to exclude` 排除范围

当前版本对跨文件搜索与替换的历史记录与文档访问流程做过重构，适合反复执行同类检索任务。

## 搜索范围控制

你可以通过两层方式控制搜索范围：

- 工作区级忽略：在工作区根目录使用 `.iwtignore`，长期排除缓存目录、构建产物或无关素材
- 临时查询过滤：在 `Files to include` / `Files to exclude` 中输入 glob 模式，例如 `*.md`、`drafts/**/*.txt`、`temp/**`

适合场景：

- 只在某类文稿中执行替换
- 临时跳过备份文件或导出目录
- 保留主工作区结构，但缩小当前搜索影响面

## 建议使用流程

1. 先搜索确认影响范围。
2. 小范围替换并检查结果。
3. 再执行全局替换。

## 使用提醒

- 涉及正则替换时，建议先在少量结果上验证表达式
- 对大量文档执行替换前，建议先确认工作区已经同步并保存
- 若结果明显过多，优先检查 `.iwtignore` 与 include / exclude 过滤条件
