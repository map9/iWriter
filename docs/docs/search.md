# 搜索与替换

> 适用版本：iWriter `0.1.7`
>
> 最后更新：2026-04-29

## 文内搜索与替换

用于当前打开文档，适合快速定位并批量修订。

适合场景：

- 修改当前章节中的高频术语
- 检查某个片段是否重复出现
- 在落稿前统一格式或标点

## 跨文件搜索与替换

`Search` 面板支持在工作区内执行全文搜索与替换。

支持能力：

- 正则表达式
- 区分大小写
- 全词匹配
- 搜索历史记录

当前版本对跨文件搜索与替换的历史记录与文档访问流程做过重构，适合反复执行同类检索任务。

## 建议使用流程

1. 先搜索确认影响范围。
2. 小范围替换并检查结果。
3. 再执行全局替换。

## 使用提醒

- 涉及正则替换时，建议先在少量结果上验证表达式
- 对大量文档执行替换前，建议先确认工作区已经同步并保存
