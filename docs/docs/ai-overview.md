# AI 总览

> 适用版本：iWriter `0.1.24`
>
> 最后更新：2026-07-27

## 两种模式

### Edit

- 面向文档编辑与改写。
- 支持 proposal/HITL 审批流。
- 适合润色、续写、重写、局部修订、结构调整等“先提案后落地”场景。

### Creative

- 面向长线小说创作，提供完整的写作闭环。
- 核心能力：规划（PlannerAgent）→ 起草（WriterAgent）→ 一致性检查（ConsistencyAgent）→ 叙事方向探索（ExplorerAgent）→ StoryBible 自动维护。
- 所有写文件操作均需作者明确审批（plan-first + HITL），支持 git 版本控制集成。
- 适合需要角色弧光、设定一致性、跨章节伏笔管理的创作项目。

## 会话与上下文

- 支持会话线程历史。
- 支持附加文本、目录、图片、PDF 等上下文。
- 提供上下文 token 统计、自动摘要阈值进度和长会话自动压缩。
- 上下文圆环是只读进度指示器；提示中会显示自动摘要阈值、本次会话的真实 token 用量、缓存命中，以及 Creative 模式下子 Agent 的输入 / 输出统计。
- 会话达到阈值后由 DeepAgents 自动生成摘要；当前不提供手动压缩入口。

## 当前实现边界

- `Edit` 模式不会直接无确认改写正文，仍然以提案审批为主。
- `Creative` 面向长线创作，不适合单次一键生成；每个写作动作均需计划与审批。
