# AI 总览

> 适用版本：iWriter `0.1.9`
>
> 最后更新：2026-05-04

## 三种模式

### Edit

- 面向文档编辑与改写。
- 支持 proposal/HITL 审批流。
- 适合润色、续写、重写、局部修订、结构调整等“先提案后落地”场景。

### Creative

- 面向创作场景。
- 适合生成草稿、提纲、文案素材并保存。
- 更适合小说、设定、人物、桥段、世界观等长线创作素材整理。

### Minimal

- 轻量对话模式。
- 不加载业务工具链。
- 适合快速问答、思路讨论、模型能力试跑。

## 会话与上下文

- 支持会话线程历史。
- 支持附加文本、目录、图片、PDF 等上下文。
- 提供上下文 token 统计与输入压缩能力。

## 当前实现边界

- `Edit` 模式不会直接无确认改写正文，仍然以提案审批为主。
- `Creative` 更偏向素材生成与保存，不是完整剧情管理系统。
- `Minimal` 不携带业务工具，因此也不会执行文档写入操作。
