# 打印、PDF 与导出

> 适用版本：iWriter `0.1.23`
>
> 最后更新：2026-07-01

iWriter 提供两套文档输出路径：**打印与 PDF 导出**（基于 paged.js 分页渲染，从 `File -> Print...` 进入）和**格式导出**（基于 Pandoc 转换引擎，从 `File -> Export` 进入）。Office 文档还可以通过 LibreOffice 转换为 PDF 进行只读预览。两者各有侧重，适合不同场景。

## 打印与 PDF 导出

打印流程基于 [paged.js](https://pagedjs.org/) 进行分页渲染，支持丰富的页面设置、分页策略和页眉页脚配置。通过打印对话框，你可以在输出前预览最终效果，并在对话框中临时覆盖所有设置——这些修改仅作用于当次输出，不会影响偏好设置中的默认值。

### 打印对话框概述

通过 `File -> Print...` 或 `⌘P` / `Ctrl+P` 打开打印对话框。对话框分为左右两栏：

- **左侧**：实时预览区，展示分页后的文档效果，支持缩放
- **右侧**：设置面板，包含打印机选择、页面范围、主题切换、页面设置、分页策略、页眉页脚等所有配置

对话框顶部显示预估的打印页数（sheets）。

对话框右上角和底部都提供关闭入口，也可以按 `Esc` 关闭。真实打印机、图片打印和 PDF 打印共享同一套基础打印设置，打印机状态会在下拉列表中显示。

### 输出模式

打印对话框支持两种输出模式：

| 模式 | 说明 |
| --- | --- |
| **真实打印机** | 选择系统中已安装的打印机，通过 Electron 的原生打印接口输出。支持选择打印机、份数、页面范围、打印质量（DPI）、色彩模式（彩色/灰度） |
| **Save as PDF** | 选择 "Save as PDF" 伪打印机，将文档保存为 PDF 文件。弹出保存对话框选择输出路径 |

### 打印主题

在打印对话框中可以临时切换打印主题，而不影响偏好设置中的默认选择。打印主题决定了：

- 打印 CSS 样式（字体、字号、颜色、间距等）
- 页面默认值（纸张大小、边距、分页策略、页眉页脚）

切换主题后，页面设置、分页策略、页眉页脚等会自动更新为新主题的默认值。如果你之前手动修改过这些设置，切换主题时会保留那些在旧主题和新主题中不同值的修改。

### 页面设置

| 设置项 | 选项 | 说明 |
| --- | --- | --- |
| **纸张大小** | A3 / A4 / A5 / A6 / A7 / A10 / B4 / B5 / Letter / Legal / Ledger | 选择输出纸张尺寸 |
| **方向** | 纵向（Portrait）/ 横向（Landscape） | 纸张方向 |
| **起始页** | 自动 / 右页（Recto）/ 左页（Verso） | 决定首页是左页还是右页。单页边距模式下，"右页"指首页右侧留更多空白；对页模式下，"右页"指首页作为右页（通常章节从右页开始） |
| **边距模式** | 普通边距（Single）/ 对页边距（Facing） | 普通边距设置上、右、下、左四项；对页边距设置上、下、内侧、外侧四项——内侧边距通常比外侧大，为装订留出空间 |
| **边距值** | 支持 CSS 长度单位（mm, cm, in, pt） | 如 `20mm`、`1in` |
| **打印背景** | 开 / 关 | 是否在打印输出中包含 CSS 背景色和背景图。深色主题建议开启此项 |

### 分页策略

分页策略控制文档内容在页面之间的分布方式。提供三种预设模式和自定义模式。

**预设模式：**

| 模式 | 说明 | 适用场景 |
| --- | --- | --- |
| **Balanced（平衡）** | 默认模式，尽量均匀分布内容，允许适度的孤行和寡行 | 通用文档 |
| **Compact（紧凑）** | 压缩空白区域，允许更灵活的分页，最大化页面利用率 | 草稿、内部文档 |
| **Strict Book（严格书籍）** | 严格的书籍排版规范，章节从右页开始，最小化孤行寡行 | 正式出版物、书籍 |

**自定义模式：** 手动修改以下任一子项后，模式自动切换为"自定义"：

**"与下一个元素保持"（keepWithNext）：**

| 选项 | 说明 |
| --- | --- |
| 标题 | 标题与紧随其后的内容保持在同一页 |
| 图片题注 | 图片题注与紧随其后的内容保持在同一页 |
| 表格题注 | 表格题注与紧随其后的内容保持在同一页 |

**"避免内部断页"（avoidBreakInside）：**

| 选项 | 说明 |
| --- | --- |
| 段落 | 不在段落内部断页 |
| 引用块 | 不在引用块内部断页 |
| 代码块 | 不在代码块内部断页 |
| 表格 | 不在表格内部断页 |
| 表格行 | 不在表格行内部断页 |
| 图片 | 不在图片元素内断页 |
| 列表项 | 不在列表项内部断页 |

**其他分页设置：**

| 设置项 | 说明 |
| --- | --- |
| **Widows（寡行）** | 段落末行最少保留行数，留空使用自动值 |
| **Orphans（孤行）** | 段落首行最少保留行数，留空使用自动值 |
| **章节起始侧** | 自动 / 右页（Recto）/ 左页（Verso），决定新章节从哪一侧开始 |
| **空白页行为** | 允许空白页 / 抑制空白页页眉页脚——当分页规则产生空白页时，是否在该页上显示页眉页脚 |

### 页眉页脚

页眉页脚系统支持 16 个标准位置（margin box），可以使用模板变量自动填充文档信息。

#### 16 个 Margin Box 位置

**页面上方（Top）：**

| 位置 | 说明 |
| --- | --- |
| `top-left-corner` | 左上角 |
| `top-left` | 页眉左 |
| `top-center` | 页眉中 |
| `top-right` | 页眉右 |
| `top-right-corner` | 右上角 |

**页面左侧（Left）：**

| 位置 | 说明 |
| --- | --- |
| `left-top` | 左侧栏上 |
| `left-middle` | 左侧栏中 |
| `left-bottom` | 左侧栏下 |

**页面右侧（Right）：**

| 位置 | 说明 |
| --- | --- |
| `right-top` | 右侧栏上 |
| `right-middle` | 右侧栏中 |
| `right-bottom` | 右侧栏下 |

**页面下方（Bottom）：**

| 位置 | 说明 |
| --- | --- |
| `bottom-left-corner` | 左下角 |
| `bottom-left` | 页脚左 |
| `bottom-center` | 页脚中 |
| `bottom-right` | 页脚右 |
| `bottom-right-corner` | 右下角 |

#### 模板变量

在 margin box 的内容模板中可以使用以下变量，打印时自动替换：

| 变量 | 说明 | 示例输出 |
| --- | --- | --- |
| `${documentTitle}` | 文档标题（取文件名，不含扩展名） | `我的小说第一章` |
| `${chapterTitle}` | 当前章节标题（来源由 chapterSource 设置决定） | `第三章 远行` |
| `${sectionTitle}` | 当前小节标题（来源由 sectionSource 设置决定） | `3.2 离别` |
| `${printDate}` | 打印日期 | `2026-05-04` |
| `${pageNo}` | 当前页码 | `42` |
| `${totalPages}` | 总页数 | `128` |

#### 首页与奇偶页

| 设置项 | 说明 |
| --- | --- |
| **首页不同** | 首页使用独立的页眉页脚配置（firstPageSlots），适用于封面页不显示页眉页脚的场景 |
| **奇偶页不同** | 左页（verso）和右页（recto）使用独立的页眉页脚配置（leftPageSlots / rightPageSlots），适用于书籍排版中左右页页眉内容不同的场景 |

**级联规则：** 当同时启用了"首页不同"和"奇偶页不同"时，优先级为：首页 > 奇偶页 > 通用设置。即首页使用 `firstPageSlots`，非首页的偶数页使用 `leftPageSlots`，非首页的奇数页使用 `rightPageSlots`。如果某个页面的专用 slots 为空，则回退使用通用 `slots`。

#### 预设模板

每个 margin box 的模板输入框旁边有一个快捷菜单（`⋯` 按钮），提供常用模板预设：

- 空（无内容）
- `${documentTitle}`
- `${chapterTitle}`
- `${sectionTitle}`
- `${printDate}`
- `Page ${pageNo}`
- `Page ${pageNo} of ${totalPages}`
- `${documentTitle} · ${pageNo}`
- `${chapterTitle} · ${pageNo}`

#### 页眉页脚开关

可以通过"启用页眉页脚"复选框整体开关页眉页脚功能。关闭后，所有页眉页脚配置会被保留但不生效。

### 运行标题（Running Title）

运行标题用于自动从文档结构中提取章节标题，供 `${chapterTitle}` 和 `${sectionTitle}` 模板变量使用。

| 设置项 | 选项 | 说明 |
| --- | --- | --- |
| **章节来源（chapterSource）** | None / H1 / H2 / H3 | 从哪个级别的标题提取章节标题 |
| **小节来源（sectionSource）** | None / H2 / H3 / H4 | 从哪个级别的标题提取小节标题 |

例如，设置 `chapterSource: H1` 和 `sectionSource: H2`，则当前页面上最近出现的 H1 标题会被提取为 `${chapterTitle}`，最近出现的 H2 标题会被提取为 `${sectionTitle}`。

### N-up 打印（每张纸多页）

在"更多设置"中可以设置每张纸上排列的页数：

| 选项 | 排列方式 |
| --- | --- |
| 1 | 每张纸 1 页（默认） |
| 2 | 每张纸 2 页（纵向纸张左右排列，横向纸张上下排列） |
| 4 | 每张纸 4 页（2×2 网格） |
| 6 | 每张纸 6 页（纵向 2×3，横向 3×2） |
| 9 | 每张纸 9 页（3×3 网格） |

N-up 布局在打印预览中实时更新，可以直观看到效果。

### 其他打印设置

| 设置项 | 说明 |
| --- | --- |
| **页面范围** | 全部 / 仅奇数页 / 仅偶数页 / 自定义范围（如 `1-5, 8, 11-13`） |
| **份数** | 打印份数（仅真实打印机，PDF 模式不适用） |
| **缩放** | 默认（自适应）/ 自定义百分比（10%–500%） |
| **打印质量** | 150 / 300 / 600 dpi（仅真实打印机） |
| **色彩模式** | 彩色 / 灰度（仅支持彩色的真实打印机） |
| **系统打印对话框** | 打开操作系统原生的打印对话框（仅真实打印机），可以使用系统级的打印机驱动设置 |

### 打印预览

打印预览基于 paged.js 的 `Previewer` 类，将文档 HTML 渲染为分页后的预览效果。预览流程：

1. 将编辑器中的 HTML 内容复制到隐藏的 iframe 中
2. 注入打印 CSS（来自所选打印主题）和 paged.js 运行时代码
3. paged.js 按 @page 规则对内容进行分页
4. 渲染完成后，预览区显示分页后的页面缩略图
5. 根据页面范围和 N-up 设置过滤和重排页面

**预览缩放：** 预览区右下角的百分比标签可以点击，自动调整为"适合页面"的缩放比例。

### 长图与长表格

当文档中包含超过单页高度的图片、表格或表格行时，预览会尽量解除过强的内部断页限制，避免内容在分页时被裁掉。跨页表格会尽量重复表头，帮助阅读连续表格内容。

如果某个元素本身无法自然拆分（例如单张超长位图），建议在输出前适当缩小图片宽度、调整页面方向或改用更大的纸张尺寸。

### mermaid 图

打印预览、真实打印和 Save as PDF 会在输出前将 `mermaid` 语言代码块渲染为 SVG 图形。图形会居中显示并尽量避免在图形内部断页。

如果 mermaid 语法有误，预览中会显示错误文本，而不是静默输出空白区域；修正文档中的源码后重新打开或刷新打印预览即可再次渲染。

## 导出

导出功能基于 [Pandoc](https://pandoc.org/) 文档转换引擎，支持将当前 Markdown 文档转换为多种常见格式。

### Pandoc 依赖

导出功能需要系统安装 Pandoc。如果未安装：

- **macOS**：`brew install pandoc`
- **Windows**：[pandoc.org/installing.html](https://pandoc.org/installing.html) 下载安装包
- **Linux**：使用系统包管理器安装，如 `apt install pandoc`

安装后，iWriter 会自动检测 Pandoc 路径。如果需要使用特定版本的 Pandoc，可以在偏好设置中手动指定路径。

### 导出流程

1. 打开要导出的 Markdown 文档
2. 通过 `File -> Export` 选择目标格式
3. 在弹出的保存对话框中选择输出位置和文件名
4. 确认后，iWriter 调用 Pandoc 执行转换
5. 转换完成后，根据偏好设置自动打开文件或在文件夹中显示

**导出格式由文件扩展名自动决定**，例如保存为 `.docx` 导出为 Word 文档，保存为 `.html` 导出为 HTML。

### 支持的导出格式

| 格式 | 扩展名 | 说明 |
| --- | --- | --- |
| **HTML** | `.html` | 独立 HTML 文件（`--standalone`），可附加自定义 CSS |
| **Word** | `.docx` | Microsoft Word 文档，可附加参考文档（reference doc） |
| **OpenOffice** | `.odt` | OpenOffice / LibreOffice 文档，可附加模板文件 |
| **RTF** | `.rtf` | 富文本格式，兼容绝大多数文字处理软件 |
| **EPUB** | `.epub` | 电子书格式，支持目录深度设置和自定义 CSS |
| **LaTeX** | `.tex` | LaTeX 源文件，适合学术论文排版 |
| **MediaWiki** | `.mediawiki` | MediaWiki 标记语言（维基百科格式） |
| **reStructuredText** | `.rst` | Python 文档常用标记语言 |
| **Textile** | `.textile` | 轻量级标记语言 |
| **OPML** | `.opml` | 大纲处理标记语言 |

### 导出偏好设置

导出偏好设置分为"通用设置"和"格式级设置"两部分。详见 [偏好设置 - 导出](/docs/preferences#导出)。

**通用设置：**

| 设置项 | 选项 | 说明 |
| --- | --- | --- |
| **默认导出目录** | 每次询问 / 源文件同目录 / 自定义目录 | 导出时默认的保存位置 |
| **Pandoc 路径** | 自动检测 / 手动指定 | Pandoc 可执行文件的路径 |
| **导出后动作** | 在文件夹中显示 / 自动打开文件 | 导出完成后的后续操作 |

**格式级设置：** 每种导出格式可以单独配置：

| 格式 | 可配置项 |
| --- | --- |
| **HTML** | 自定义参数、CSS 文件路径 |
| **Word (.docx)** | 自定义参数、参考文档路径（`--reference-doc`） |
| **OpenOffice (.odt)** | 自定义参数、模板文件路径（`--reference-doc`） |
| **RTF** | 自定义参数 |
| **EPUB** | 自定义参数、CSS 文件路径、目录深度（`--toc-depth`） |
| **LaTeX** | 自定义参数 |
| **MediaWiki** | 自定义参数 |
| **reStructuredText** | 自定义参数 |
| **Textile** | 自定义参数 |
| **OPML** | 自定义参数 |

**自定义参数**可以直接输入 Pandoc 命令行参数（如 `--number-sections --toc`），这些参数会追加到自动生成的命令之后。

**参考文档（reference doc）**用于 DOCX/ODT 格式：提供一个模板文件，Pandoc 会使用该文件的样式（字体、字号、颜色、页边距等）来格式化输出，而不是使用 Pandoc 的默认样式。

**CSS 文件**用于 HTML/EPUB 格式：提供自定义的 CSS 样式表，Pandoc 会将其嵌入到输出文件中。

**EPUB 目录深度**：控制 EPUB 电子书的目录层级（1–6 级标题）。

### 导出命令预览

在每项格式的设置页中，有一个只读的"参数预览"输入框，展示当前配置下实际执行的 Pandoc 命令参数（完整命令可以通过日志查看）。这可以帮助你验证自定义参数是否正确。

基础命令格式为：

```
pandoc -f gfm -s -o <outputPath> -t <targetFormat> [自定义参数...]
```

所有导出均以 GitHub Flavored Markdown（`gfm`）为源格式，生成独立文件（`--standalone`）。

## 导入

导入功能同样基于 Pandoc，支持将外部文档格式转换为 iWriter 可编辑的 Markdown。

### 支持的导入格式

| 格式 | 扩展名 |
| --- | --- |
| Word | `.docx` |
| OpenOffice | `.odt` |
| RTF | `.rtf` |
| EPUB | `.epub` |
| HTML | `.html`, `.htm` |
| LaTeX | `.tex`, `.latex` |
| MediaWiki | `.mediawiki`, `.wiki` |
| reStructuredText | `.rst`, `.rest` |
| Textile | `.textile` |
| OPML | `.opml` |

### 导入流程

1. 通过 `File -> Import Document...` 选择要导入的文件
2. iWriter 根据扩展名自动识别源格式
3. 调用 Pandoc 将源文件转换为 GFM（GitHub Flavored Markdown）
4. 转换后的 Markdown 内容以 `.md` 格式保存到工作区中
5. 新文件自动在编辑器中打开

导入过程中的任何错误都会以通知方式提示，包括不支持的格式、Pandoc 未安装、转换失败等情况。

## Office 文档预览

iWriter 可以打开 `.doc`、`.docx`、`.xls`、`.xlsx`、`.ppt`、`.pptx` 文件。Office 文档不会直接进入编辑器，而是通过 LibreOffice 转换为临时 PDF 后，使用内置 PDF 查看器预览。

### LibreOffice 依赖

Office 预览需要系统安装 LibreOffice。未检测到 LibreOffice 时，预览页会显示安装命令、LibreOffice 下载入口、重新检测按钮，以及“用系统应用打开”的备用操作。

默认检测路径：

- **macOS**：优先检测 `/Applications/LibreOffice.app/Contents/MacOS/soffice`，再回退到 PATH
- **Windows**：优先检测 `C:\Program Files\LibreOffice\program\soffice.exe` 和 `C:\Program Files (x86)\LibreOffice\program\soffice.exe`
- **Linux**：检测 PATH 中的 `soffice`

如果 LibreOffice 安装在非默认位置，可在 [偏好设置 - 导出](/docs/preferences#导出) 中手动指定 LibreOffice 路径。Windows 上建议填写 `...\LibreOffice\program\soffice.exe` 或对应 `program` 目录的绝对路径，iWriter 会从该目录启动转换，减少转换 PDF 时找不到 LibreOffice 组件的情况。

### 预览与导入

- 预览转换结果会缓存在系统临时目录中，源文件内容或修改时间变化后会重新转换。
- 转换失败时，页面会显示错误信息，并提供重新尝试和用系统应用打开。
- `.docx` 文件可从 Office 预览页或标签页右键菜单导入为 Markdown 草稿。导入仍依赖 Pandoc，并会避免对同一来源重复创建同名导入标签。

## 常见问题

### Pandoc 未安装

- 导出/导入按钮在 Pandoc 未安装时仍然可见，但点击后会提示安装
- 可通过偏好设置中的"检查 Pandoc"确认安装状态
- 安装 Pandoc 后可能需要重启 iWriter 或重新配置路径

### 打印预览与实际输出不一致

- 打印预览基于 paged.js 的屏幕渲染，与真实打印机的输出可能存在细微差异
- 建议在正式打印前先导出为 PDF 检查效果
- 深色主题打印时请确保开启了"打印背景"选项，否则深色底可能显示为白色

### 自定义主题不生效

- 确认 `screen.css` 文件存在于主题文件夹中
- 确认 CSS 规则使用了正确的 `.tiptap.markdown-theme-{id}` 选择器
- 检查偏好设置中是否已选择该自定义主题
- 查看主题列表中的加载状态是否有错误提示

### 导出格式兼容性

- Pandoc 对不同格式的支持程度不同，某些格式可能丢失部分 Markdown 特性（如任务列表、数学公式等）
- 复杂的表格、嵌套列表在转换为某些格式时可能需要手动调整
- LaTeX 导出适合学术场景，但需要本地 LaTeX 发行版才能进一步编译为 PDF
