# 故障排查

> 适用版本：iWriter `0.1.10`
>
> 最后更新：2026-05-08

## 无法打开工作区

- 确认目录权限可读写。
- 确认目录未被系统安全策略拦截。

## 跨文件搜索无结果

- 检查是否选中了正确工作区。
- 检查正则、大小写、全词选项是否设置过严。

## AI 请求失败

- 检查 Provider、API Key、Base URL、模型名。
- 检查网络与代理连通性。

## 图片 / PDF 无法显示

- 检查文件是否损坏。
- 检查是否属于支持格式。

## 更新失败

- 确认在生产环境中运行。
- 确认能访问 GitHub Releases。
- 必要时走手动下载安装覆盖。
