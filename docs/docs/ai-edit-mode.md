# AI Edit 模式与审批流

> 适用版本：iWriter `0.1.7`
>
> 最后更新：2026-04-29

## 流程图

```text
用户提出编辑目标
  -> AI 读取上下文并生成提案
  -> 用户逐项决策（approve / edit / reject）
  -> 仅已通过提案写入文档
  -> 用户保存
```

## 三种决策

- `approve`：接受该提案
- `edit`：手动修改提案后再执行
- `reject`：拒绝该提案，不写入

## 安全边界

- 不会在未审批情况下直接写盘。
- 提案机制用于降低误改风险。

## 失败与回退

- 网络或 Provider 异常时，提案可能生成失败。
- 可调整提示词后重试，或先手动编辑再继续 AI 协作。
