# 更新机制

> 适用版本：iWriter `0.1.10`
>
> 最后更新：2026-05-08

iWriter 支持自动检查和下载更新，发现新版本后会弹出更新对话框，由你决定何时安装。

## 更新流程

1. 应用启动后，若已启用"启动时检查更新"，会在几秒后自动检查
2. 检测到新版本后，自动弹出更新对话框
3. 可选择立即更新、稍后提醒或跳过当前版本
4. 开始下载后，下载在后台继续进行
5. 下载完成后对话框切换为"可安装"状态
6. 确认安装后，应用退出并进入安装流程

## 更新对话框

发现更新后，界面会展示当前版本、新版本、发布日期、下载大小和更新说明。

- `Update Now`：开始下载更新
- `Install Now`：下载完成后执行安装
- `Remind Me Later`：关闭提示，稍后再处理
- `Skip This Version`：跳过此版本号，后续同版本不再提示
- `View Details`：查看对应版本的发布说明

## 自动更新控制

在偏好设置的 `更新` 分组中，可以控制以下选项：

- 启用自动更新
- 启动时检查更新
- 自动下载更新
- 自动安装更新
- 更新通道：`稳定版` / `测试版`
- 检查间隔：按小时设置自动检查频率
- 立即检查更新

默认配置中：

- 自动更新为开启
- 启动时检查更新为开启
- 自动下载更新为开启
- 自动安装更新为关闭
- 检查间隔为 `24` 小时
- 更新通道默认为 `稳定版`

## 注意事项

- 关闭"自动更新"后，自动下载和自动安装不会继续执行，但仍可手动检查更新
- 更新通道支持 `稳定版` 与 `测试版`，实际可获取到的版本取决于发布端是否提供对应版本
- "跳过当前版本"会记录具体版本号，而不是永久关闭更新提示
- 更新说明优先来自 GitHub Release 正文；发布工作流会自动从 `docs/changelog.md` 生成这部分内容
- 若发布页缺少详细说明，应用会尝试回退到远程 `docs/changelog.md` 对应版本内容；仍不可用时才展示简短默认提示
- 自动更新仅在生产环境启用；本地开发构建不会触发真实更新
- 发布源当前为 GitHub Releases：<https://github.com/map9/iWriter/releases>
