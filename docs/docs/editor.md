# 编辑器使用

> 适用版本：iWriter `0.2.2`
>
> 最后更新：2026-07-28

iWriter 的编辑器基于 Tiptap / ProseMirror 构建，同时支持 Markdown 语法输入和可视化富文本编辑，两种方式可以混用。

## Markdown 与富文本双模式

编辑器不是纯粹的 Markdown 源码编辑器，而是"所见即所得"的富文本模式，同时支持 Markdown 语法快捷输入：

- **直接输入 Markdown 语法**：在行首输入 `#` 并按空格自动转为标题，输入 `**文字**` 自动加粗，输入 `-`（后跟空格）创建列表，其余格式同理。
- **斜杠菜单**：在空行或段落起始处输入 `/`，可搜索并插入标题、列表、引用、代码块、数学公式、mermaid 图、分隔线、表格和图片。
- **工具栏操作**：选中文字后点击工具栏按钮应用格式，无需记忆语法。
- **结果一致**：两种方式产生相同的文档结构，文件以 `.iwt` / `.md` 存储为标准格式。

## 支持的文件格式

| 格式 | 说明 |
| --- | --- |
| `.iwt` | iWriter 原生格式，完整保留样式信息 |
| `.md` / `.markdown` | 标准 Markdown，与其他工具互通 |
| `.txt` | 纯文本，无格式 |

Office 文档（`.doc`、`.docx`、`.xls`、`.xlsx`、`.ppt`、`.pptx`）会以只读预览方式打开，不会直接进入 Markdown 编辑器。若要继续编辑 `.docx` 内容，可在 Office 预览页或标签页右键菜单中选择导入为 Markdown。

## 行内格式

| 格式 | Markdown 语法 | 快捷键 |
| --- | --- | --- |
| 粗体 | `**文字**` | `⌘B` / `Ctrl+B` |
| 斜体 | `*文字*` | `⌘I` / `Ctrl+I` |
| 下划线 | — | `⌘U` / `Ctrl+U` |
| 删除线 | `~~文字~~` | `⌘⇧X` / `Ctrl+Shift+X` |
| 高亮 | `==文字==` | — |
| 行内代码 | `` `代码` `` | `⌘E` / `Ctrl+E` |
| 链接 | `[文字](url)` | `⌘K` / `Ctrl+K` |

## 块级元素

### 标题

在行首输入 `#` 到 `######`（H1–H6）后按空格自动转换，或从工具栏选择标题级别。

### 列表

| 类型 | 输入方式 |
| --- | --- |
| 无序列表 | 行首输入 `-` 或 `*`，后跟空格 |
| 有序列表 | 行首输入 `1.`，后跟空格 |
| 任务列表 | 行首输入 `- [ ]`，后跟空格 |

任务列表项可以直接点击复选框切换完成状态。

### 引用块

行首输入 `>`（后跟空格）创建引用块，可以嵌套多层。

### GFM Alerts 与写作批注

iWriter 支持 GitHub Flavored Markdown Alert：

```markdown
> [!NOTE]
> 这是一条补充说明。
```

支持 `NOTE`、`TIP`、`IMPORTANT`、`WARNING`、`CAUTION`，并为 AI Story Buddy 小说流程增加：

- `BEAT`：章节中的叙事 / 情感节拍
- `COMMENT`：作者或编辑留下的正文批注

在空引用块中输入 `> [!TYPE]` 后按空格，可以直接转换为带图标的 Alert。保存回 Markdown 时会保留标准标记；普通引用块不会被误判为 Alert。

### 代码块

行首连续输入三个反引号后按回车创建代码块，在开头的反引号之后可以指定语言（如 `python`、`javascript`），编辑器会自动应用对应语言的语法高亮。

代码块工具栏中的语言下拉默认显示常用语言，便于快速选择。若需要完整语言列表，可在 [偏好设置](/docs/preferences#编辑器) 中将“代码块语言列表”切换为“全部支持的语言”。

当代码块语言设置为 `mermaid` 时，编辑器会将代码渲染为图表预览。你可以在图表预览与源码编辑之间切换，并在 Mermaid 编辑状态下调整源码 / 预览的布局方向。

### 表格

在工具栏点击"插入表格"，或在正文中输入 Markdown 表格语法后自动渲染。已有表格支持：

- 点击单元格选中所在行/列
- 通过上下文菜单插入或删除行/列
- 拖动列边界调整宽度

### 数学公式

| 类型 | 输入方式 |
| --- | --- |
| 行内公式 | 用 `$` 包裹，如 `$E=mc^2$` |
| 块级公式 | 行首连续输入两个 `$` 后按回车 |

公式使用 KaTeX 渲染，支持常见 LaTeX 数学符号。

### 图片与媒体

- 工具栏点击"图片"按钮选择本地图片插入
- 支持拖拽图片文件到编辑区
- 支持通过斜杠菜单插入图片占位，再选择本地图片或粘贴图片链接
- 图片节点支持拖拽右下角调整尺寸
- 图片工具栏支持左对齐、居中、右对齐与两端对齐
- 图片工具栏支持复制图片、用系统默认程序打开本地图片，以及编辑图片路径或 URL
- 支持音频/视频文件的链接嵌入
- 图片、表格、代码块、公式块在编辑器内都有对应的节点工具

### mermaid 图

mermaid 图使用 `mermaid` 语言代码块保存，适合流程图、时序图、ER 图等结构化图示。可以通过 `/` 选择 **mermaid 图** 快速插入，也可以手动创建 `mermaid` 代码块。

如果 Mermaid 语法有误，图表区域会显示错误信息；修正源码后会重新渲染。

打印和 PDF 导出时，iWriter 会将 `mermaid` 代码块预渲染为图形；语法错误时，预览中会显示对应错误，方便在输出前修正。

### 右键菜单

编辑器正文支持页面级右键菜单。右键菜单会根据当前文档类型提供常用编辑、插入和视图操作；图片查看器与 PDF 查看器也有各自的页面菜单。文件标签页也支持右键菜单，可关闭其他标签、关闭已保存标签、定位文件、复制路径，或将可导入的 Office 文件转换为 Markdown 草稿。

## 视图与写作模式

- `Clean Mode`：尽量弱化界面干扰，保留正文与核心操作
- `Focus Mode`：收束视觉注意力，适合长时间专注阅读或改稿
- `Typewriter Mode`：让当前输入区域尽量保持在舒适视线位置

这些模式可以组合使用，用来在”排版操作”和”沉浸写作”之间切换。

## Markdown 主题

编辑器支持切换 Markdown 内容的显示主题，改变字体、颜色、间距等视觉样式，不影响文档内容本身。

- 内置 `system`、`github`、`github-dark`、`prose`、`novel` 五套主题，覆盖系统原生排版、技术文档、通用文章和小说创作等场景
- 屏幕主题和打印主题可独立选择，例如屏幕使用深色主题、打印使用浅色主题
- 支持加载自定义 CSS 主题，放在 `~/.iwriter/markdown/themes/` 目录即可自动识别
- 自定义主题支持热更新，保存 CSS 文件后无需重启 App

主题选择在偏好设置的”显示”分组中管理。详细的主题编写指南、CSS 变量参考和 theme.json 配置见 **[Markdown 主题系统](/docs/markdown-themes)**。

## 打印与 PDF 导出

详细的打印工作流、页面设置、分页策略、页眉页脚配置和 N-up 打印见 **[打印、PDF 与导出](/docs/print-export#打印与-pdf-导出)**。

核心要点：
- 支持从 `File -> Print...` 进入打印预览流程，基于 paged.js 进行分页渲染
- 打印对话框支持选择 **Markdown 打印主题**，可临时切换主题而不影响偏好设置
- 支持配置页面大小、方向、边距（普通边距 / 对页边距）、起始页语义（recto / verso）
- 支持三种分页策略预设（`Balanced` / `Compact` / `Strict Book`）和自定义模式
- 支持 16 个页眉页脚位置（margin box），6 个模板变量（`${documentTitle}`、`${chapterTitle}`、`${sectionTitle}`、`${printDate}`、`${pageNo}`、`${totalPages}`）
- 支持首页与奇偶页使用不同的页眉页脚，支持运行标题自动提取
- 支持真实打印机输出与 Save as PDF 两种模式
- 支持 N-up 打印（每张纸 1/2/4/6/9 页）

打印主题与打印默认值可在 [偏好设置](/docs/preferences) 的”Markdown 主题”分组中统一管理，打印对话框的修改只作用于本次输出，不回写到主题或偏好设置。

## 格式导出

导出功能基于 Pandoc 转换引擎，支持将 Markdown 文档导出为多种常见格式。详细的导出配置见 **[打印、PDF 与导出](/docs/print-export#导出)**。

- 支持导出为 HTML、Word（`.docx`）、OpenOffice（`.odt`）、RTF、EPUB、LaTeX、MediaWiki、reStructuredText、Textile、OPML
- 需要系统安装 [Pandoc](https://pandoc.org/)，macOS 可通过 `brew install pandoc` 安装
- 每种格式可单独配置定制参数、参考文档、CSS 样式等
- 导出目录、Pandoc 路径、导出后动作可在 [偏好设置](/docs/preferences#导出) 中配置

## 导入已有文稿

导入功能同样基于 Pandoc，详细的导入配置见 **[打印、PDF 与导出](/docs/print-export#导入)**。

- 支持从 `File -> Import Document...` 导入常见文稿格式（Word、ODT、RTF、EPUB、HTML、LaTeX 等）
- 导入后的内容转换为 GFM（GitHub Flavored Markdown），在 iWriter 中继续编辑
- 打开 `.docx` 文件时，也可以从 Office 预览页或标签页右键菜单直接导入为 Markdown
- 如果需要自定义 Pandoc 路径，可在 [偏好设置](/docs/preferences#导出) 中配置

## 粘贴行为

- 从浏览器或 Word 粘贴：自动将 HTML 格式转换为编辑器的富文本格式，保留标题、加粗、列表等结构，去除内联样式。
- 粘贴纯文本：通过“粘贴为纯文本”按原始文本插入，不附加格式；系统原生粘贴快捷键保持平台默认行为。
- 粘贴图片：直接将图片嵌入文档当前光标位置。
- 当前版本已修复部分“粘贴为纯文本”和图片粘贴相关问题，遇到异常可优先升级到最新版本后重试。

## 搜索替换（文内）

编辑器内置搜索替换面板（`⌘F` / `Ctrl+F`），适合单文档内快速定位和批量修改。跨文件搜索请参考 [搜索与替换](/docs/search)。

## 拼写与语法检查

在输入时实时标记拼写和语法问题。相关设置（引擎选择、语言配置等）在 [偏好设置](/docs/preferences) 的"拼写与语法"分组中配置。

## 保存行为

- **自动保存**：内容变化后自动保存，默认开启，可在偏好设置中关闭。
- **手动保存**：`⌘S` / `Ctrl+S`
- **全部保存**：`⌘⇧S` / `Ctrl+Shift+S`，保存所有已打开的文档。
- **只读模式**：系统或用户标记为只读的文件会显示提示，防止误改。
