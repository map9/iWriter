# 编辑器使用

> 适用版本：iWriter `0.1.7`
>
> 最后更新：2026-04-29

iWriter 的编辑器基于 Tiptap / ProseMirror 构建，同时支持 Markdown 语法输入和可视化富文本编辑，两种方式可以混用。

## Markdown 与富文本双模式

编辑器不是纯粹的 Markdown 源码编辑器，而是"所见即所得"的富文本模式，同时支持 Markdown 语法快捷输入：

- **直接输入 Markdown 语法**：在行首输入 `#` 并按空格自动转为标题，输入 `**文字**` 自动加粗，输入 `-`（后跟空格）创建列表，其余格式同理。
- **工具栏操作**：选中文字后点击工具栏按钮应用格式，无需记忆语法。
- **结果一致**：两种方式产生相同的文档结构，文件以 `.iwt` / `.md` 存储为标准格式。

## 支持的文件格式

| 格式 | 说明 |
| --- | --- |
| `.iwt` | iWriter 原生格式，完整保留样式信息 |
| `.md` / `.markdown` | 标准 Markdown，与其他工具互通 |
| `.txt` | 纯文本，无格式 |

## 行内格式

| 格式 | Markdown 语法 | 快捷键 |
| --- | --- | --- |
| 粗体 | `**文字**` | `⌘B` / `Ctrl+B` |
| 斜体 | `*文字*` | `⌘I` / `Ctrl+I` |
| 下划线 | — | `⌘U` / `Ctrl+U` |
| 删除线 | `~~文字~~` | `⌘⇧X` / `Ctrl+Shift+X` |
| 高亮 | `==文字==` | — |
| 行内代码 | `` `代码` `` | `⌘E` / `Ctrl+E` |
| 链接 | `[文字](url)` | `⌘K` / `Ctrl+K` |

## 块级元素

### 标题

在行首输入 `#` 到 `######`（H1–H6）后按空格自动转换，或从工具栏选择标题级别。

### 列表

| 类型 | 输入方式 |
| --- | --- |
| 无序列表 | 行首输入 `-` 或 `*`，后跟空格 |
| 有序列表 | 行首输入 `1.`，后跟空格 |
| 任务列表 | 行首输入 `- [ ]`，后跟空格 |

任务列表项可以直接点击复选框切换完成状态。

### 引用块

行首输入 `>`（后跟空格）创建引用块，可以嵌套多层。

### 代码块

行首连续输入三个反引号后按回车创建代码块，在开头的反引号之后可以指定语言（如 `python`、`javascript`），编辑器会自动应用对应语言的语法高亮。

### 表格

在工具栏点击"插入表格"，或在正文中输入 Markdown 表格语法后自动渲染。已有表格支持：

- 点击单元格选中所在行/列
- 通过上下文菜单插入或删除行/列
- 拖动列边界调整宽度

### 数学公式

| 类型 | 输入方式 |
| --- | --- |
| 行内公式 | 用 `$` 包裹，如 `$E=mc^2$` |
| 块级公式 | 行首连续输入两个 `$` 后按回车 |

公式使用 KaTeX 渲染，支持常见 LaTeX 数学符号。

### 图片与媒体

- 工具栏点击"图片"按钮选择本地图片插入
- 支持拖拽图片文件到编辑区
- 支持音频/视频文件的链接嵌入
- 图片、表格、代码块、公式块在编辑器内都有对应的节点工具

## 视图与写作模式

- `Clean Mode`：尽量弱化界面干扰，保留正文与核心操作
- `Focus Mode`：收束视觉注意力，适合长时间专注阅读或改稿
- `Typewriter Mode`：让当前输入区域尽量保持在舒适视线位置

这些模式可以组合使用，用来在“排版操作”和“沉浸写作”之间切换。

## 打印与导出 PDF

- 支持从 `File -> Print...` 进入打印流程
- 会根据当前文档类型准备打印参数
- 支持打印预览、打印机选择以及导出 PDF
- 适合小说、简历、普通文稿等需要正式输出的场景

## 粘贴行为

- 从浏览器或 Word 粘贴：自动将 HTML 格式转换为编辑器的富文本格式，保留标题、加粗、列表等结构，去除内联样式。
- 粘贴纯文本：按原始文本插入，不附加格式。
- 粘贴图片：直接将图片嵌入文档当前光标位置。
- 当前版本已修复部分“粘贴为纯文本”和图片粘贴相关问题，遇到异常可优先升级到最新版本后重试。

## 搜索替换（文内）

编辑器内置搜索替换面板（`⌘F` / `Ctrl+F`），适合单文档内快速定位和批量修改。跨文件搜索请参考 [搜索与替换](/docs/search)。

## 拼写与语法检查

在输入时实时标记拼写和语法问题。相关设置（引擎选择、语言配置等）在 [偏好设置](/docs/preferences) 的"拼写与语法"分组中配置。

## 保存行为

- **自动保存**：内容变化后自动保存，默认开启，可在偏好设置中关闭。
- **手动保存**：`⌘S` / `Ctrl+S`
- **全部保存**：`⌘⇧S` / `Ctrl+Shift+S`，保存所有已打开的文档。
- **只读模式**：系统或用户标记为只读的文件会显示提示，防止误改。
