# 更新日志

> 适用版本：iWriter `0.1.10`
>
> 最后更新：2026-05-08

## `0.1.10`

- 重构 Creative 模式执行与审阅流程，新增创作会话摘要、审阅状态同步与本地创作数据存储。
- 新增 Creative 工具能力与内置写作技能，支持场景结构、角色声音、深度视角等创作辅助。
- AI Provider 配置新增模型能力与额外参数支持，改进模型选择、DeepSeek 参数传递与线程运行时解析。
- 优化打印预览背景与 Markdown 打印主题样式，预览与实际页面观感更一致。
- 改进标题栏与资源管理器布局记忆等界面细节。

## `0.1.9`

- 新增 Markdown 屏幕预览与打印主题系统，内置多套主题，支持一键切换。
- 支持加载本地 CSS 文件并创建自定义 Markdown 主题，满足个性化排版需求。
- 重构打印对话框与打印设置面板，新增发布 / 导出偏好设置，打印与导出流程更一致。
- 新增导入 / 导出能力（Pandoc 驱动），支持多格式转换与导出偏好配置。
- 改进资源管理器面板交互，优化编辑区与侧边栏之间的文件操作体验。
- 支持工作区忽略规则，减少资源管理器与搜索结果中的无关文件干扰。

## `0.1.8`

- 新增跨文件搜索结果过滤，提升工作区内批量检索与替换效率。
- 改进资源管理器与搜索面板的筛选体验，并同步优化相关状态持久化。
- 文档站点与应用内帮助入口持续对齐当前 GitHub Pages 结构。
- 修复文档站点发布流程中的构建问题与若干界面细节。

## `0.1.7`

- 文档站点与应用内帮助入口持续对齐当前 GitHub Pages 结构。

## `0.1.6`

- 改进跨文件搜索与替换的历史记录与文档访问流程。
- 修复部分 AI Provider 模型名与 DeepSeek `reasoning_content` 兼容问题。
- 修复应用在部分设备休眠 / 唤醒后的内容恢复问题。
- 修复打印中不可见字符相关问题。
- 修复部分粘贴为纯文本与编辑提案弹层体验问题。

## `0.1.5`

- 完成桌面端核心工作流闭环：工作区、编辑器、搜索、AI 面板。
- AI 支持 `Edit / Creative / Minimal` 三模式。
- `Edit` 模式提供 proposal/HITL 审批流程。
- 增强图片与 PDF 文档查看体验。
- 引入生产环境自动更新机制。
