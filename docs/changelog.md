# 更新日志

> 适用版本：iWriter `0.1.15`
>
> 最后更新：2026-06-02

## `0.1.15`

- 新增 Markdown 编辑区 `1024px` 页面宽度选项，补充固定宽度与流式宽度之间的阅读 / 写作布局选择。
- 升级 TipTap、LangChain、deepagents 等关键依赖，并补充不可见字符扩展补丁，改善编辑器与 AI Agent 运行稳定性。
- 优化编辑器高亮层实现，区分块级与行内高亮，修复数学公式高亮矩形位置异常。
- 修复链接 / 数学公式弹出工具在表格容器内的定位与展开问题，并补充链接打开按钮。
- 改进图片粘贴与图片地址识别，支持占位图片处理与粘贴后跳转到图片节点。
- 修复 IWT 转 Markdown 时 `<br>` 丢失的问题。
- 修复表格重复操作总是作用于第一个表格、表头状态变更异常、尺寸提示与表头颜色等问题。
- 优化状态栏、Tooltip、通知、偏好设置与部分侧边栏界面的配色和多语言文案。
- 修复最近打开文件的打开流程，并补充未处理菜单动作上报。

## `0.1.13`

- **AI Agent 架构重构**。Creative / Edit domain 拆分为独立策略，流式事件、工具调用、HITL 审批与审阅面板进一步统一，提升多轮任务的稳定性和可维护性。
- **Creative 模式：SubAgent 编排增强**。Planner、Writer、Consistency、Explorer、Researcher、WritingStyleExtractor、WritingStyleSkillCreator 等子代理分工更清晰，子任务进度、思考内容、工具调用和结果会在右侧 AI 面板中分层展示。
- **Creative 模式：叙事方向探索**。在故事关键分叉点，可以让 agent 同时草拟 2–3 个走向，通过对比卡片查看每个方向的情节摘要、后续影响和示例正文，选定后一键融合到草稿。
- **Creative 模式：Git 版本控制集成**。在有 git 仓库的工作区内，agent 会在关键节点（章节完成、里程碑）主动提议提交或打 tag，作者可审批、编辑提交信息或拒绝，所有 git 操作均需明确批准。
- **Creative 模式：研究与写作风格支持**。新增 Researcher 子代理与作者写作风格提取 / 生成流程，可围绕资料、时代背景、作者风格和作品分析进行更聚焦的创作辅助。
- **Creative 模式：写作技法提升**。WriterAgent 新增感官接地、展示与叙述、伏笔植入三类写作技法参考，正文在具象感和结构精度上有明显改善。
- **Creative 模式：一致性检查增强**。ConsistencyAgent 现在会额外检测已植入伏笔是否被遗忘（伏笔审计）以及角色弧光是否停滞或突变（弧光推进检查）。
- **Creative 模式：StoryBible 压缩**。写作推进后 StoryBible 内容超过阈值时，agent 会主动建议将已完成章节归档为摘要，保持上下文窗口的有效利用，归档操作不删除任何现有内容。
- **Creative 模式：StoryBible 顶层锚定**。新项目启动时 StoryBible 模板新增 Premise（核心前提）、Theme（主题）、Promise to Reader（读者承诺）三个基础章节，agent 在建立角色之前会先引导作者填写这三项。
- **Creative 模式：章节管理**。支持通过 agent 对话创建、删除、重命名、重排章节文件，操作均需审批，支持自动级联重编号。
- **Creative 模式：语言一致性**。agent 自动检测作者输入语言，对话、写作计划、逻辑分析与一致性建议全部以同一语言输出。
- **Markdown 数学公式增强**。新增 `\(...\)` 与 `\[...\]` 数学公式分隔符支持，并修复数学公式保存丢失、LaTeX 打印报错等问题。
- **PDF 导出增强**。导出 PDF 时启用文档大纲与 Tagged PDF 生成，改善 PDF 结构信息与辅助功能兼容性。
- **编辑器显示模式**。新增 Markdown 编辑区页面宽度选择，支持固定 768、固定 1280 与流式宽度，便于在不同屏幕和写作场景间切换。
- **标签页与标题栏体验优化**。支持拖拽调整标签页顺序、拖放文件到标题栏打开，并优化未保存、只读、外部修改和已删除文件状态的展示。
- **外部文件变更处理增强**。改进非工作区已打开文件的外部修改 / 删除处理，工作区目录被删除或恢复时的状态提示更可靠。
- **依赖与构建维护**。升级 TipTap、deepagents、Electron 相关依赖，补充 Electron main 进程类型检查，并调整生产环境安全配置。
