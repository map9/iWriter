# 更新日志

> 适用版本：iWriter `0.1.12`
>
> 最后更新：2026-05-10

## Unreleased

- **Creative 模式：叙事方向探索**。在故事关键分叉点，可以让 agent 同时草拟 2–3 个走向，通过对比卡片查看每个方向的情节摘要、后续影响和示例正文，选定后一键融合到草稿。
- **Creative 模式：Git 版本控制集成**。在有 git 仓库的工作区内，agent 会在关键节点（章节完成、里程碑）主动提议提交或打 tag，作者可审批、编辑提交信息或拒绝，所有 git 操作均需明确批准。
- **Creative 模式：写作技法提升**。WriterAgent 新增感官接地、展示与叙述、伏笔植入三类写作技法参考，正文在具象感和结构精度上有明显改善。
- **Creative 模式：一致性检查增强**。ConsistencyAgent 现在会额外检测已植入伏笔是否被遗忘（伏笔审计）以及角色弧光是否停滞或突变（弧光推进检查）。
- **Creative 模式：StoryBible 压缩**。写作推进后 StoryBible 内容超过阈值时，agent 会主动建议将已完成章节归档为摘要，保持上下文窗口的有效利用，归档操作不删除任何现有内容。
- **Creative 模式：StoryBible 顶层锚定**。新项目启动时 StoryBible 模板新增 Premise（核心前提）、Theme（主题）、Promise to Reader（读者承诺）三个基础章节，agent 在建立角色之前会先引导作者填写这三项。
- **Creative 模式：章节管理**。支持通过 agent 对话创建、删除、重命名、重排章节文件，操作均需审批，支持自动级联重编号。
- **Creative 模式：语言一致性**。agent 自动检测作者输入语言，对话、写作计划、逻辑分析与一致性建议全部以同一语言输出。

## `0.1.12`

- 新增自动保存间隔配置，支持在偏好设置中自定义保存频率，并同步优化相关状态持久化逻辑。
- 调整首次打开时的自动保存与校对初始化行为，减少启动阶段的干扰。
- 修复文件被外部修改后的处理流程，改进编辑器标签状态与内容同步表现。
- 修复 Creative domain 下内置技能无法正常调用的问题，并补充创作能力与提示词相关适配。
- 更新 UI 设计文档，补充最新界面设计说明。

## `0.1.11`

- 新增发布说明提取与回退机制，GitHub Release 正文与应用内更新对话框可更稳定地展示版本更新内容。
- 改进自动更新相关文档与发布工作流，自动生成 release notes。
- 优化资源管理器树形交互，区分展开与重命名模式，减少误触并提升文件管理体验。
- 修复多语言文案缺失问题，并补齐 Linux / Windows 下部分应用菜单与窗口行为。

## `0.1.10`

- 重构 Creative 模式执行与审阅流程，新增创作会话摘要、审阅状态同步与本地创作数据存储。
- 新增 Creative 工具能力与内置写作技能，支持场景结构、角色声音、深度视角等创作辅助。
- AI Provider 配置新增模型能力与额外参数支持，改进模型选择、DeepSeek 参数传递与线程运行时解析。
- 优化打印预览背景与 Markdown 打印主题样式，预览与实际页面观感更一致。
- 改进标题栏与资源管理器布局记忆等界面细节。

## `0.1.9`

- 新增 Markdown 屏幕预览与打印主题系统，内置多套主题，支持一键切换。
- 支持加载本地 CSS 文件并创建自定义 Markdown 主题，满足个性化排版需求。
- 重构打印对话框与打印设置面板，新增发布 / 导出偏好设置，打印与导出流程更一致。
- 新增导入 / 导出能力（Pandoc 驱动），支持多格式转换与导出偏好配置。
- 改进资源管理器面板交互，优化编辑区与侧边栏之间的文件操作体验。
- 支持工作区忽略规则，减少资源管理器与搜索结果中的无关文件干扰。
