# 更新日志

> 适用版本：iWriter `0.1.24`
>
> 最后更新：2026-07-28

## Unreleased

### 新增

- 新增独立“文档版本管理”偏好页，可统一配置 Git 可执行文件、全局 / 当前仓库提交身份、无暂存内容时的提交行为、Pull 自动暂存、Fetch prune、Diff 默认布局和版本视图。
- 新增完整的 Git 文档版本管理面板：支持仓库检测、初始化与克隆，按已暂存 / 未暂存 / 冲突 / 未跟踪分组查看变更，并可按列表或目录树浏览。
- 新增文件、目录、整组和 hunk 级暂存 / 取消暂存 / 放弃操作；支持 Commit、Commit All、Amend、撤销上次提交，并在缺少 Git 用户信息时引导配置。
- 新增分支与远程工作流：创建、重命名、切换、合并、删除和发布分支，管理 remote，以及 Fetch、Pull、Push、Sync；危险操作会先执行预检并说明影响。
- 新增编辑区 Diff 标签页：支持并排 / 内联对比、行号、差异导航和概览；未暂存文本可直接编辑，冲突文件提供 ours / theirs 对照与可编辑合并结果。
- 新增仓库 Graph 与文件 Timeline：可查看分支泳道、全部分支、提交文件、分支 / tag 标记，支持从历史提交创建分支或标签、恢复单个文件、管理 stash 和推送 tags。
- 新增 Explorer 与状态栏 Git 状态：文件树显示 Git 装饰，状态栏显示当前分支、领先 / 落后、同步进度和变更数。
- 小说创作搭子（AI Story Buddy）改为纯 Markdown 小说项目：项目、世界观、人物、总纲 / 卷纲 / 章纲、正文、素材、过程记录、探索稿和写作风格都有明确的文件目录与模板，不再依赖单一 StoryBible 或创作数据库。
- 新增 AI Story Buddy 阶段技能：创意与提纲、正文撰写、精修、跨章重构、小说导入和风格蒸馏；支持工作区 `.iwriter/skills/` 中的项目级自定义技能。
- 新增 Writer / Reviewer 专用子 Agent 与写作会话：作者确认写作意图后，正文修改在会话内累积，最终以整章差异卡统一接受、反馈返工或拒绝回滚。
- 新增已有小说导入：通过 Pandoc 机械转换并在 dry-run 中识别章节、卷、前后材料，作者确认映射后拆分到 `manuscript/`；还可从现有正文反向重建项目、人物、世界观和提纲。
- 新增 GFM Alerts 富文本支持：`NOTE`、`TIP`、`IMPORTANT`、`WARNING`、`CAUTION`，以及小说流程使用的 `BEAT`、`COMMENT` 均可在编辑器中显示图标并稳定往返 Markdown。
- 新增 `System` Markdown 主题，使文档排版更贴近系统字体与平台显示习惯。

### 改进

- 统一文档版本管理与 AI Story Buddy Git 工具的执行链路，复用同一个 GitService、Git 路径、仓库级串行队列、锁重试和错误规整；文档工作流的 Pull 固定使用 merge 策略。
- 重构 AI Story Buddy 提示词、角色与技能装配，主 Agent 负责编排，Writer 只写正文、Reviewer 只读评审；章纲确认、可选 beat、正文撰写与精修职责进一步分离。
- 改进 AI Story Buddy 评审与返工：支持 developmental、consistency、line 和 reader-validation 等评审视角，评审结论保留证据位置，并按正文、beat、提纲或作者决策进行分流。
- 改进 AI 文档读取与编辑：长内容可按预算分页读取，列表以容器为单位编辑，同轮多条提案可批量提交，块 ID 变化后的失败诊断更清晰。
- 升级 LangChain、LangGraph、DeepAgents 与 TipTap，并适配新版流事件、推理内容和工具 schema。
- 改进模型调用稳定性：临时限流会尊重 `Retry-After` 重试，主模型持续失败时可切换备用模型并在界面提示。
- 改进 AI 长会话上下文管理：上下文进度、发送前预算检查与自动摘要统一使用 DeepAgents 的模型预算；缺少模型 profile 时使用 DeepAgents 自身默认阈值，圆环改为只读状态指示。
- 改进 AI 搜索工具：支持正则 alternation、中文全词匹配、无结果提示和更清晰的命中摘要；Web Research 改由主 Agent 按需编排通用子 Agent。
- 改进跨文件搜索：结果摘要包含更有用的上下文，中文与全词匹配更准确，外部结果高亮会在搜索失效时及时清理。
- 改进工作区过滤：`.iwtignore`、Explorer、搜索和文件监听可分别选择是否复用 `.gitignore`；默认过滤 `.git/`、`.iwriter/` 与系统元数据。
- 改用原生工作区文件监听并减少侧边栏调整大小时的文件树重算；支持直接创建文件夹，长文件名采用省略显示，文件重命名后窗口标题会同步更新。
- 改进标签页架构以承载文档、Diff 和合并视图；文档版本管理、Explorer、弹出工具和状态栏的布局与交互保持一致。
- 移除 Provider 的 Temperature、Top P、Frequency Penalty 和 Presence Penalty 配置，避免不同模型接口对采样参数支持不一致。

- 修复外部文件修改与内部保存并发时可能把文件写成 0 字节的问题，并阻止编辑器初始加载完成前的自动保存。

- 修复长时间 AI 流式输出偶发卡住的问题，增加结束排空与超时保护，并改进子 Agent 推理与消息归属。
- 修复 DeepSeek reasoner / V4 空 content、`reasoning_content` 回传，以及 Gemini 工具 schema 兼容问题。
- 修复列表块编辑、按 block ID 修改、创建文档和写作会话范围判断的多处边界问题。
- 修复 Git 并发刷新、`index.lock`、外部 Git 变更、重命名 Diff、新文件暂存 / 放弃、引用分类和分支图连线等稳定性问题。
- 修复原生粘贴与“粘贴为纯文本”、Markdown 代码块空行、搜索结果定位、高亮层和表格 / 图片弹出工具定位等编辑器问题。

## `0.1.13`

- **AI Agent 架构重构**。Creative / Edit domain 拆分为独立策略，流式事件、工具调用、HITL 审批与审阅面板进一步统一，提升多轮任务的稳定性和可维护性。
- **Creative 模式：SubAgent 编排增强**。Planner、Writer、Consistency、Explorer、Researcher、WritingStyleExtractor、WritingStyleSkillCreator 等子代理分工更清晰，子任务进度、思考内容、工具调用和结果会在右侧 AI 面板中分层展示。
- **Creative 模式：叙事方向探索**。在故事关键分叉点，可以让 agent 同时草拟 2–3 个走向，通过对比卡片查看每个方向的情节摘要、后续影响和示例正文，选定后一键融合到草稿。
- **Creative 模式：Git 版本控制集成**。在有 git 仓库的工作区内，agent 会在关键节点（章节完成、里程碑）主动提议提交或打 tag，作者可审批、编辑提交信息或拒绝，所有 git 操作均需明确批准。
- **Creative 模式：研究与写作风格支持**。新增 Researcher 子代理与作者写作风格提取 / 生成流程，可围绕资料、时代背景、作者风格和作品分析进行更聚焦的创作辅助。
- **Creative 模式：写作技法提升**。WriterAgent 新增感官接地、展示与叙述、伏笔植入三类写作技法参考，正文在具象感和结构精度上有明显改善。
- **Creative 模式：一致性检查增强**。ConsistencyAgent 现在会额外检测已植入伏笔是否被遗忘（伏笔审计）以及角色弧光是否停滞或突变（弧光推进检查）。
- **Creative 模式：StoryBible 压缩**。写作推进后 StoryBible 内容超过阈值时，agent 会主动建议将已完成章节归档为摘要，保持上下文窗口的有效利用，归档操作不删除任何现有内容。
- **Creative 模式：StoryBible 顶层锚定**。新项目启动时 StoryBible 模板新增 Premise（核心前提）、Theme（主题）、Promise to Reader（读者承诺）三个基础章节，agent 在建立角色之前会先引导作者填写这三项。
- **Creative 模式：章节管理**。支持通过 agent 对话创建、删除、重命名、重排章节文件，操作均需审批，支持自动级联重编号。
- **Creative 模式：语言一致性**。agent 自动检测作者输入语言，对话、写作计划、逻辑分析与一致性建议全部以同一语言输出。
- **Markdown 数学公式增强**。新增 `\(...\)` 与 `\[...\]` 数学公式分隔符支持，并修复数学公式保存丢失、LaTeX 打印报错等问题。
- **PDF 导出增强**。导出 PDF 时启用文档大纲与 Tagged PDF 生成，改善 PDF 结构信息与辅助功能兼容性。
- **编辑器显示模式**。新增 Markdown 编辑区页面宽度选择，支持固定 768、固定 1280 与流式宽度，便于在不同屏幕和写作场景间切换。
- **标签页与标题栏体验优化**。支持拖拽调整标签页顺序、拖放文件到标题栏打开，并优化未保存、只读、外部修改和已删除文件状态的展示。
- **外部文件变更处理增强**。改进非工作区已打开文件的外部修改 / 删除处理，工作区目录被删除或恢复时的状态提示更可靠。
- **依赖与构建维护**。升级 TipTap、deepagents、Electron 相关依赖，补充 Electron main 进程类型检查，并调整生产环境安全配置。
