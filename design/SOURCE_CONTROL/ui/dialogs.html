Source Control 对话框 — 对齐工程

三类分开：① 独立纯破坏性确认用工程现有的原生 showMessageBox；② 需输入用工程 dialog 外壳；③ 可恢复、未知或需要解释风险的 Git 状态也用工程 dialog 外壳，默认给出原因和下一步，原始输出收进「技术详情」。

实现映射：原生确认只用于放弃、中止合并等独立不可逆操作。选择分支后立即尝试安全删除；未合并分支由项目内风险对话框一次性说明并确认强制删除，避免重复弹窗。输入与错误恢复复用覆盖层 bg-black/45 backdrop-blur + rounded-box border-base-300 bg-base-100；错误正文不显示 raw stderr，用户展开 技术详情 后才可查看/复制。
