Source Control 对话框 — 真实场景清单 + 预检内容

本页穷举 iWriter SCM 真实会出现的每一个对话框/提示，逐条对应真实函数（store → GitApi）。三种形态：① IwDialog（工程外壳·文本输入） ② 列表管理对话框（列表 + 逐项操作） ③ 原生 showMessageBox（一切确认/预检/失败）。分支的选择走菜单（见 panel.html），此处不含选择器。

总纲 · 预检 → 说明 → 决策（绝不"先做后警"）：可能出问题的操作执行前先跑预检。无问题 → 非破坏性直接执行、破坏性弹一次防误点确认；有问题 → 原生框把问题用大白话列成信息 + 取消 + 强制/继续。 能翻译的问题用大白话、不堆术语；程序没识别出的报错（unknown）则把 git 原始输出作为提示正文 + 可复制——否则用户无从排障/上报。真实可预检的操作只有三个：切换分支 / 删除分支 / 合并分支。全部错误一律原生 messagebox，工程对话框 GitErrorResolutionDialog 退役。
现状差异（本次要改）：切换脏树、删除未合并分支现在都是事后触发（promptDirtyCheckout / deleteBranch 失败后 presentGitIssue）→ 改为事前预检。合并现在无确认直接 merge() → 补预检。新增主进程预检：preflightCheckout / preflightDeleteBranch / preflightMerge，返回 { ok, problems[], canForce }。

3 · 原生 messagebox · 预检结果（真实可预检的三个操作）

操作前跑预检，把问题用大白话列出，让用户在 取消 / 强制 之间决定。每卡下方标出「预检查什么」。

store.checkout · 有更改（现 promptDirtyCheckout）
⚠️

切换到 develop

当前有未提交的更改，需要先处理才能切换。

预检 preflightCheckout：工作区是否干净 —— status 的 staged / changes / untracked 是否有内容。
干净 → 直接 checkout；有更改 → 上框。三个动作＝stashPush(-u)→checkout / checkout -m（冲突进 Merge Changes）/ checkout -f（丢弃）。
store.deleteBranch · 预检有问题
⚠️

删除分支 feature/old？

这个分支还有未处理的内容：

  • 有 3 处改动还没有推送到远程
  • 还没有合并进 main
  • 另一个分支 feature/sub 是从它分出来的

删除后将无法从这里找回。

预检 preflightDeleteBranch（三查）： ① 未推送：分支相对其 upstream 是否 ahead（无 upstream 视为从未推送）； ② 未并入 main：branch --merged main 是否含它； ③ 有派生：branch --contains <tip> 是否有其他本地分支。 任一命中 → 上框（强制删除）。受保护：main / master / 当前分支不进候选（菜单不列）。
store.deleteBranch · 预检通过（防误点）
🗑️

删除分支 feature/done？

您确认要删除吗？

已并入 main、无未推送提交、无派生分支，可安全删除。

预检通过 → 仍弹一次防误点确认（普通「删除」按钮，非「强制」）。
store.merge（现无确认，直接 merge）
❓

把 develop 合并进 main？

这不是快进合并，会生成一个合并提交；如果有冲突，会进入冲突解决。

预检 preflightMerge：能否快进 —— merge-base --is-ancestor 判断当前分支是否为目标祖先。
可快进 → 提示"将直接快进"；需合并提交 → 上框。冲突不预测（真合并时进 Merge Changes）。

4 · 原生 messagebox · 无法预检的失败（真实 GitIssueKind）

这些要真正联网/操作后才知道，无法事前预检。已识别的（auth/network/落后）给大白话 + 恢复动作；未识别的（unknown）把 git 原始输出作为提示正文，并给「复制错误信息」。全部原生 messagebox。

GitIssue · remote-auth（push/pull/fetch/publish/clone）
🔒

没有访问远程的权限

当前账号无法访问 origin，请检查凭证后重试。

GitIssue · network
📡

无法连接远程

网络连接失败，请检查网络后重试。

GitIssue · remote-non-fast-forward（push 被拒）
⚠️

远程有更新，无法直接推送

远程已有你本地没有的提交，需要先拉取合并再推送。

GitIssue · unknown（兜底：git 输出作为提示正文）
⚠️

合并分支未能完成

Git 报告了以下错误：

error: Your local changes to the following files would be overwritten by merge: draft/ch001.md Please commit your changes or stash them before you merge.
