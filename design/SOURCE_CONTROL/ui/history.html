Explorer 容器（Workspace + Timeline）· Timeline/Graph 空状态

Explorer 与 SCM 都是「视图容器 + 多 viewer」。Timeline 的两个 viewer：一个在 Explorer（Timeline，可选），一个在 SCM（Graph，见 panel.html）。

容器与 viewer 归属

  1. Explorer 容器 = 工作区 Workspace（文件树，必选，不可隐藏）+ 时间线 Timeline（可选）。通过 Explorer 标题栏 ⋯ 菜单勾选。
  2. SCM 容器 = 存储库 Repositories + 更改 Changes + 图谱 Graph（见 panel.html）。Timeline 的「第二张设计」= SCM 的 Graph viewer。
  3. Timeline 跟随当前活动文件；文件右键「查看文件历史」聚焦该文件的 Timeline。

正常态

空状态（无仓库 / 无提交 / Timeline 空）
