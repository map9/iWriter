SCM 面板 — 视图容器 / 行状态 / 菜单

SCM = 视图容器 + 三个可折叠 viewer（存储库 / 更改 / 图谱）。本页定死：① 变更行的状态常驻最右、hover 按钮出现在其左侧不遮挡；② tree 模式目录行带聚合状态色点（对标 VSCode）；③ 菜单为扁平分组，分支的删除/合并/发布走子菜单列分支，切换在存储库菜单内直接列分支点击。

实现映射：容器 = SidebarMode.SOURCE_CONTROL；行组件 GitChangeGroup.vue（去掉 hover 隐藏状态，操作区改为状态左侧内联）；目录聚合色点 = 子树最高严重度（冲突/删除=红 ▸ 修改/重命名=黄 ▸ 新增/未跟踪=绿）；分支子菜单/切换列表复用 showContextMenu 的 submenu；删除/合并点分支 → 预检（preflightDeleteBranch/Merge）→ 原生确认。
