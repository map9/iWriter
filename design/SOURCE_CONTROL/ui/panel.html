SCM 面板 — 视图容器（Repositories / Changes / Graph）

SCM 是一个视图容器，含三个可折叠 viewer：① 存储库 Repositories（原分支条）② 更改 Changes（原变更树 + 提交框）③ 图谱 Graph（提交历史，原时间线 View B）。容器 ⋯ 只处理跨 viewer 的 Remote / Stash / Tags / 视图；分支归 Repositories ⋯。

实现映射：容器 = SidebarMode.SOURCE_CONTROL，内部由多个 viewer section 组成（VSCode view-container 模型）· Changes 必选、Repositories/Graph 可选（容器 ⋯ 菜单 checkbox 切换）· Repositories ⋯ 仅分支操作/切换 · Changes 标题栏保留「全部暂存」与「列表/树切换」，全量放弃收进变更分组或更多入口 · 每个 viewer 独立折叠。
