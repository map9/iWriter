iWriter · Source Control UI 视觉设计稿

对标 VSCode Source Control。配色为 daisyUI 浅色，贴合工程。信息架构：Explorer / SCM 均为视图容器 + 多个可折叠 viewer。

  • panel.html — SCM 容器 三个 viewer：存储库 Repositories / 更改 Changes / 图谱 Graph · 含 ⋯ 菜单与空/引导态
  • history.html — Explorer 容器 + 空状态 工作区 Workspace(必选) + 时间线 Timeline(可选) · ⋯ 勾选菜单 · 无仓库/无提交/Timeline 空
  • dialogs.html — 对话框 纯确认走原生 showMessageBox；需输入走工程 dialog 外壳
  • diff-view.html — Diff 查看器 复用 agent 的 DiffSplitView + hunk 暂存 / 冲突编辑器 / 二进制降级
  • preferences.html — 偏好设置 版本控制分区：引擎 / 提交行为 / 同步 / Diff / 装饰 / 忽略规则
  • statusbar.html — 状态栏 Git 组件 工厂式 statusbar-item（分支 / 同步），command 派发
